AT A GLANCE

한줄 요약

강체 링크의 관성 파라미터(질량·1차 모멘트·회전관성, 링크당 10개)를 최소제곱으로 식별할 때, “물리적으로 존재할 수 있는 질량 분포”라는 조건(질량 양수 + 회전관성 주값의 삼각부등식)이 4×4 유사관성 행렬 J(π) ≻ 0 이라는 선형행렬부등식(LMI) 하나와 같음을 보이고, 이를 제약으로 넣은 반정부호계획(SDP) 으로 전역 최적 식별을 하는 방법이다. 링크가 CAD 타원체 안에 있다는 조건도 LMI + 선형 부등식으로 추가된다. MIT Cheetah 3 다리 한 쪽(3 DoF, 강체 6개)에서 검증했다.

01 / BACKGROUND

1. 연구 배경

1.1 문제 정의 (§I, p.1)

  • 모델 기반 전신 제어(다리 로봇의 최적화 제어)는 정확한 동역학 모델이 필요하고, 그 핵심이 관성 파라미터 식별이다.
  • 역동역학은 관성 파라미터 π 에 선형(식 2)이라 최소제곱이 쉽다. 그러나 제약 없이 풀면 잡음·부족한 자극 때문에 어떤 실제 물체에도 해당하지 않는 값(음의 질량, 삼각부등식 위반 관성)이 나온다(p.3).
  • 부동 기저(다리 로봇)에서는 관절 토크 없이 접촉력·기구학만으로 식별하는 경우도 있어(Ayusawa 2011) 제약이 더 중요하다.

1.3 연구 기여 (§I, p.2)

  1. 완전한 물리 일관성 조건을 π 에 대한 LMI 로 표현 → 전역 최적 SDP.
  2. 그 조건이 “질량 분포의 밀도 가중 공분산이 양반정부호”라는 통계적 뜻임을 보임(모멘트 문제와 연결).
  3. 경계 타원체 안에서의 밀도 실현 가능성 제약을 새로 유도(고전 모멘트 문제 Thm 4.7(b)).
  4. Cheetah 3 다리에서 링크 관성 + 로터 관성 + 마찰을 함께 식별하여 검증.

🔧 HR35 대조 — 왜 이 논문인가

HR35 트윈(AGX)은 링크별 질량·질량중심·관성 개별값을 요구한다. 그런데 실차 식별(Werner 2025)은 곱(묶음)만 준다. 이 논문은 “묶음을 맞추면서 개별값이 물리적으로 말이 되게 고르는” 도구다. 또 현재 URDF 관성에 기준점 오류가 기록돼 있어(hr35_urdf_kmm_pdf_consistency_analysis.md), 데이터 없이도 지금 값이 J≻0 인지 검사할 수 있다.

03 / CORE TECHNIQUES

3. 핵심 기술

3.1 반일관성과 완전 일관성 (§III, p.3)

Ī = ĪC + mS(c)S(c)T (8)
  • 반일관성(Def. 4, Thm 1 [13]): m > 0, ĪC ≻ 0 ⇔ I(π) ≻ 0 (6×6 LMI). 운동에너지가 양수라는 조건이지만 밀도 실현을 보장하지 않는다.
  • 완전 일관성(Def. 5, Thm 2 [14]): ĪC = RJRT 의 주값이 삼각부등식을 만족해야 한다:
J1 + J2 ≥ J3,　J2 + J3 ≥ J1,　J1 + J3 ≥ J2 (9)

Traversaro 는 이를 (R ∈ SO(3), J, c, m) 다양체 위 비선형 최적화로 다뤘다 — 전역 최적 보장 없음.

직관 — 삼각부등식은 어디서 오나

회전관성의 주값은 J1 = ∫(y²+z²)ρ, J2 = ∫(x²+z²)ρ, J3 = ∫(x²+y²)ρ 다. 각 좌표의 2차 모멘트를 μ1 = ∫x²ρ 등으로 두면 J1 = μ2+μ3, J2 = μ1+μ3, J3 = μ1+μ2 (식 18). μi ≥ 0 이므로 J1+J2−J3 = 2μ3 ≥ 0. “각 방향 2차 모멘트가 음수일 수 없다” 가 삼각부등식의 정체다. 두께 0 인 판(μ3=0)이 등호 경우.

3.2 삼각부등식 → 행렬 부등식 → 공분산 (§IV.A~B, p.4)

J1 + J2 + J3 ≥ 2Ji　(i=1,2,3) (10) ½ Tr(ĪC) ≥ λmax(ĪC) (11)
λmax(ĪC) xTx ≥ xTĪCx　⇒　λmax13 ⪰ ĪC (12) ½ Tr(ĪC)13 − ĪC ⪰ 0 (13)

밀도 가중 공분산:

ĪC = ∫(Tr(xcxcT)13 − xcxcT)ρ dx (14) ΣC := ∫xcxcTρ dx (15)
ĪC = Tr(ΣC)13 − ΣC (16) ΣC = ½ Tr(ĪC)13 − ĪC (17)
J1 = μ2+μ3,　J2 = μ1+μ3,　J3 = μ1+μ2 (18)

(13) 과 (17) 을 비교하면 삼각부등식 ⇔ ΣC ⪰ 0 (Prop. 1). 즉 “물리 일관성 = 질량 양수 + 질량 분포의 공분산이 양반정부호”(Cor. 1). 확률변수의 공분산이 반드시 양반정부호인 것과 같은 수학이다(Remark 4).

3.3 유사관성 행렬과 LMI (§IV.C, Thm 3, p.5)

Σ = ∫xxTρ dx = ΣC + mccT (19,20) Σ = ½ Tr(Ī)13 − Ī　(π 에 선형)

증명(Schur 보수): J ≻ 0 ⇔ m > 0, Σ − (1/m)hhT ≻ 0. Σ = ΣC + mccT 이고 (1/m)hhT = mccT 이므로 조건은 ΣC ≻ 0 ⇔ (Prop. 1) 삼각부등식 + ĪC ≻ 0 ⇔ (Thm 2) 완전 일관성. ∎

기호뜻
Σ원점 기준 2차 모멘트 행렬
ΣC질량중심 기준 = 밀도 가중 공분산
J(π)유사관성(pseudo-inertia) 행렬. 오래된 로봇 문헌의 “모멘트 행렬”(Bejczy 1974 [36], Uicker 1967 [37])

이 논문의 핵심 한 줄

6×6 공간 관성 I(π) ≻ 0 은 반일관성, 4×4 유사관성 J(π) ≻ 0 은 완전 일관성이다. 삼각부등식이 정확히 그 둘의 차이이며, 4×4 가 더 작아 계산도 싸다(p.5). 운동에너지는 ½vTIv = ½Tr(VJVT) 로 두 표현이 연결된다.

3.4 경계 타원체 제약 (§V, p.6)

𝒮 = {x : (x−xs)TQs−1(x−xs) ≤ 1} (21)

질량중심이 안에:

밀도 자체가 안에서 실현 가능(Thm 4, 모멘트 문제 [26] Thm 4.7(b)): 𝒮 = {x : [x;1]TQ[x;1] ≥ 0} 로 쓰면

J(π) ≻ 0　and　Tr(J(π)Q) ≥ 0 (23)

이때 π 는 𝒮 안 점질량 4개로 표현 가능. (22) 만으로는 부족하다 — 질량중심이 타원체 가장자리에 가까우면 큰 2차 모멘트가 타원체 밖 질량을 뜻하게 된다(p.6).

Cor. 2: 여러 타원체의 합집합(굴착기 붐처럼 굽은 부재)에도 확장 — 각 조각 πj 가 자기 타원체에서 실현 가능하고 합이 π.

6.3 도구 의사코드 (과제 ③, 이해용)

# 이해용 의사코드 — cvxpy 스타일. 실제 구현 시 링크마다 π_i ∈ R^10, J(π_i) 는 π_i 에 선형.
import cvxpy as cp, numpy as np

def pseudo_inertia(pi):                       # pi = [m, hx, hy, hz, Ixx, Ixy, Ixz, Iyy, Iyz, Izz] (원점 기준)
    m, h, Ibar = pi[0], pi[1:4], sym3(pi[4:10])
    Sigma = 0.5*cp.trace(Ibar)*np.eye(3) - Ibar          # 식 (20)
    return cp.bmat([[Sigma, cp.reshape(h,(3,1))],[cp.reshape(h,(1,3)), cp.reshape(m,(1,1))]])

def choose_consistent(pi_prior, lumped_A, lumped_b, Q_ellipsoid, w=1e-6):
    pis = [cp.Variable(10) for _ in range(3)]            # 붐·암·버킷
    cons = []
    for pi, Q in zip(pis, Q_ellipsoid):
        J = pseudo_inertia(pi)
        cons += [J >> 1e-9*np.eye(4), cp.trace(J @ Q) >= 0]     # Thm 3, 식 (23)
    cons += [lumped_A @ cp.hstack(pis) == lumped_b]      # Werner 묶음 등식 (식 13·18 의 π_g, π_I)
    obj = cp.Minimize(w*sum(cp.sum_squares(pi - p0) for pi, p0 in zip(pis, pi_prior)))
    cp.Problem(obj, cons).solve(solver="SCS")            # 또는 MOSEK
    return [pi.value for pi in pis]

라벨링

이 도구가 내놓는 개별 질량·관성은 “측정과 모순 없고 물리적으로 존재 가능한 한 배치”다. “식별된 질량”이라 부르지 않는다. 비식별 방향(과제 ⑤)은 사전값이 정한다.

Q2. 관성 파라미터 10개와 선형성 — 왜 원점 기준인가

뉴턴-오일러 식에서 한 강체의 힘·모멘트는 mẍC, ĪCω̇ 처럼 나오는데 xC = xO + c 를 넣으면 mc 와 mccT 가 등장한다. h = mc 로 두고 Ī = ĪC + mS(c)S(c)T 로 원점 기준 관성을 정의하면 곱이 사라져 π 에 선형이 된다. 이것이 (2) 의 회귀형이 성립하는 이유이며, 최소제곱이 볼록인 이유다.

트윈(URDF)은 (m, c, ĪC) 를 쓴다. 변환: h = mc, Ī = ĪC + m(‖c‖²1 − ccT). 검사(과제 ①)는 이 변환 후 J 를 만든다.

Q3. 삼각부등식의 물리적 예 — 상자와 막대

점질량 분포의 2차 모멘트가 μ = (μ1,μ2,μ3) 이면 (18) 로 J = (μ2+μ3, μ1+μ3, μ1+μ2).

  • 상자 μ = (2, 5, 1) → J = (6, 3, 7): 6+3 ≥ 7, 3+7 ≥ 6, 6+7 ≥ 3 ✓ (Fig. 2(a) 의 ΣC = diag(2,5,1), IC = diag(6,3,7) 과 일치).
  • 얇은 막대(x 축) μ = (μ1, 0, 0) → J = (0, μ1, μ1): 등호 두 개. 막대 축 둘레 관성이 0 이라는 익숙한 사실.
  • 위반 예 J = (1, 1, 3): 1+1 < 3 → μ3 = (J1+J2−J3)/2 = −0.5 < 0 — z 방향 2차 모멘트가 음수여야 하므로 어떤 물체도 아니다. 최소제곱은 잡음이 있으면 이런 값을 낼 수 있다.

Q4. 식 (16)(17)(18) 유도

(14) 의 피적분 Tr(xcxcT)1 − xcxcT 를 적분하면 Tr(ΣC)1 − ΣC = (16). 양변 trace: Tr ĪC = 3Tr ΣC − Tr ΣC = 2Tr ΣC. 이를 (16) 에 되돌리면 ΣC = Tr(ΣC)1 − ĪC = ½Tr(ĪC)1 − ĪC = (17) ✓. (16) 은 ΣC 와 ĪC 가 같은 고유벡터를 갖고 고유값이 Ji = Tr ΣC − μi 임을 뜻하므로 (18) ✓.

Q6. 확률·통계 대응이 주는 직관 (Remark 4, 5)

밀도 ρ 를 질량으로 나누면 확률밀도 p = ρ/m 이고, 질량중심은 평균, ΣC/m 은 공분산이다. “어떤 확률변수의 공분산이 될 수 있는 행렬”은 정확히 양반정부호 행렬이다(Remark 4) — 그래서 물리 일관성이 곧 공분산 PSD 다. Remark 5 의 은 확률론의 “1차·2차 모멘트가 어떤 분포의 것일 조건”이고, J(π) 는 그것을 질량 m 으로 스케일한 것이다.

이 직관의 쓸모: 불확실성을 말할 때 자연스럽다. 링크 질량 분포를 “정확히 모른다”는 것을 확률분포로 표현하고 그 모멘트로 관성을 계산하면 자동으로 일관성이 보장된다.

Q7. 경계 타원체 (21)~(23) — 왜 (22) 만으로 부족한가

  • (22) 는 c ∈ 𝒮 를 Schur 보수로 쓴 LMI: mQs − (h − mxs)(h − mxs)T/m ⪰ 0 ⇔ (c−xs)TQs−1(c−xs) ≤ 1.
  • 그러나 질량중심이 안에 있어도 2차 모멘트가 크면 질량이 타원체 밖에 있어야 한다(Fig. 3 위 오른쪽). 질량중심이 경계로 가면 분포는 점질량으로 퇴화해야 하므로 2차 모멘트가 0 에 가야 한다(아래 두 사례).
  • Thm 4: 타원체를 [x;1]TQ[x;1] ≥ 0 로 쓰면, 밀도 실현 가능 ⇔ J ≻ 0 이고 Tr(JQ) ≥ 0. 후자는 “타원체 함수의 기댓값이 0 이상” — 분포 전체가 평균적으로 안에 있다는 조건이며, 모멘트 문제 이론(Bertsimas & Sethuraman [35], Thm 4.7(b) [26])이 이것이 충분조건임을 보장한다.
  • 굴착기 붐처럼 굽은 부재는 타원체 하나로 안 덮인다 → Cor. 2 의 합집합(조각별 πj 합).

  • 검증 RMS 1.48/1.16/1.16 N·m 대비 쿨롱 3.12/1.25/0.95 N·m — 잔차가 쿨롱 마찰 크기와 비슷하다. 즉 정지 부근 마찰 모델 오차가 잔차의 주된 몫일 수 있다(Fig. 4 의 17.5 s 사례와 정합).
  • RMS 집계 불일치: 세 값의 제곱평균 √((1.48²+1.16²+1.16²)/3) = 1.28, 단순평균 1.27 ≠ 캡션 1.46. 스택 벡터 전체 RMS 등 다른 집계일 수 있으나 본문에 정의가 없다.

Q9. 표본 수 효과(Fig. 6) — 왜 제약이 빨리 수렴시키나

최소제곱은 표본이 적을 때 잡음 방향으로 해가 튄다(과적합). 제약은 해가 놓일 수 있는 영역을 “물리적 원뿔”로 자르므로, 데이터가 부족해 튀려는 방향 중 비물리적인 쪽이 잘린다. 타원체 제약은 그 원뿔을 더 좁힌다(형상 정보 추가). Remark 6: 링크가 많을수록 물리 영역의 상대 부피가 지수적으로 줄어 이득이 커진다.

HR35 에 주는 뜻: 실차 데이터가 적고 잡음이 큰 우리 상황(20 Hz 경사계, 압력 카운트)에서 제약의 가치가 크다. 반대로 말하면 제약 없는 최소제곱으로 트윈 관성을 “보정”하면 비물리적 값이 나올 확률이 높다.

Q10. 기저 파라미터 vs 물리 일관성 — 서로 다른 두 문제

  • 기저 파라미터(Gautier & Khalil 1990): 회귀행렬 Y 의 열이 선형종속이라 어떤 파라미터 조합은 토크에 영향이 없고, 다른 조합은 항상 묶여서만 나타난다. 그 독립 조합의 수가 기저 파라미터 수다. 평면 3R 팔(회전축 평행, 중력이 평면 안)은 링크당 재편성된 3개(ZZR, MXR, MYR), 총 9개. 개별 질량 mj 는 앞 링크 항에 재편성돼 따로 안 나온다 — Werner 2025 요약 Q3 의 “중력 묶음 독립 6개” 와 같은 현상.
  • 물리 일관성: 어떤 π 가 실제 물체일 수 있는가. 비식별 방향과 무관하게 “π 가 놓일 수 있는 영역”을 정한다.
  • 둘의 관계: 비식별 방향으로는 데이터가 아무 말도 안 하므로 그 방향의 값은 (a) 사전값 정규화, (b) 물리 일관성·타원체 제약이 정한다. 본 논문은 (a) 를 wπ 로 넣었고 비식별 자체는 논하지 않았다.
  • HR35: 기저 파라미터 9개(+마찰)만 데이터로 정해지고, 나머지(30 − 9 = 21 개 방향)는 사전값·제약이 정한다. 과제 ④⑤ 가 그 수와 감도를 드러낸다.

Q11. HR35 평면 팔에 적용할 때의 축소와 주의

  • 평면 운동이면 π 의 10개 중 평면 밖 성분(hy, Ixy, Iyz 등 — 회전축을 y 로 둘 때)은 데이터에 안 나타난다. 그래도 J(π) 검사는 3차원 전체로 해야 한다(평면 밖 성분이 비물리적이어도 평면 토크엔 안 보이지만 트윈은 3차원으로 돌기 때문).
  • 트윈 URDF 관성 기준점 오류가 기록돼 있다(hr35_urdf_kmm_pdf_consistency_analysis.md). 기준점을 잘못 잡으면 (8) 의 평행축 항이 틀려 J 가 부정부호가 될 수 있다 — 과제 ① 이 이를 잡는다.
  • 타원체는 새 버킷 메시(bucket_spec, 2026-09-22 확정) 기준으로 만든다. 옛 버킷(AK 830/840) 메시로 만들면 실차와 다르다.
  • 토크는 압력→η→τ 경로(Werner 요약 §3.1)로만 얻을 수 있으므로, 이 논문의 식별(회귀) 단계는 압력 보정·면적 확정 뒤로 미룬다. 검사·선택기(과제 ①②③)는 그 전에 만들 수 있다.

PERSONAL NOTE

나의 의견 (HR35 적용)

Werner 2025 가 “실차에서 나오는 것은 묶음뿐”이라 했고, 트윈(AGX)은 링크별 개별값을 요구한다. 이 논문은 그 사이를 잇는 도구다: 묶음을 등식 제약으로, 물리 일관성(J≻0)과 메시 타원체를 부등식 제약으로, 아주대 사전값을 정규화로 넣어 존재 가능한 한 배치를 전역 최적으로 고른다. 실차 데이터 없이 당장 할 수 있는 일은 §6 과제 ①(현재 트윈 관성의 J≻0 검사)이고, 결과가 음수면 URDF 기준점 오류가 확정된다. 이 논문의 언어(“일관성 있는 한 해”)를 파라미터 지도의 identifiability 열에 그대로 쓴다.
