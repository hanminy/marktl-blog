Executive summary

핵심은 모델 하나가 아니라
학습의 순환이다.

로봇 파운데이션 모델을 RL로 엔드투엔드 학습하기는 아직 어렵다. 대신 제너럴리스트는 탐색을 돕고, 스페셜리스트는 숙련 데이터를 돌려준다.

Generalist · VLA

넓게 알고, 일반화한다

대규모 데이터에서 지식·언어 이해·행동 사전확률을 습득한다. RL 토큰과 기본 액션을 통해 스페셜리스트의 탐색을 부트스트랩한다.

RL 토큰 · 행동 prior
숙련 롤아웃 · 증류

Specialist · RL

좁게 파고들어, 완벽해진다

실제 환경에서 샘플효율 RL로 병목 과제를 빠르고 견고하게 숙달한다. 성공·실수·복구 경험을 제너럴리스트에 되돌린다.

01 · Motivation

텍스트 계획을 넘어
물리 세계로

“집을 청소하고, 빨래를 개고, 저녁을 차려줘”라는 요청에 LLM은 실행 계획을 설명한다. 우리가 원하는 답은 설명이 아니라 “On it!”과 실제 수행이다.

필요한 능력

새로운 환경·물체·시나리오로 일반화하면서, 다단계의 오픈엔디드 지시를 끝까지 수행해야 한다.

02 · Foundation model recipe

Pre-training은 지식,

01

Pre-training

많이 보고, 많이 안다

Common Crawl·Wikipedia 같은 대규모 데이터를 선별하고 학습해 사실과 패턴을 폭넓게 축적한다. 특정 과제를 푸는 것보다 지식의 기반을 만드는 단계다.

02

Post-training / Alignment

아는 것을 과제에 쓴다

고품질 SFT 데이터와 RLHF 같은 알고리즘을 통해 지식을 실제 문제 해결에 배치한다. 로봇에서는 이 단계가 속도와 숙련도를 결정한다.

03 · The supervised ceiling

“여러 가지를 그럭저럭”에서
멈추는 이유

상보 관계

지도학습은 지식과 일반화를, RL은 특정 과제의 숙달과 속도를 준다. 둘은 대체재가 아니라 서로 다른 결핍을 채운다.

스페셜리스트 롤아웃 수집

성공 결과뿐 아니라 상태에 따른 폐루프 행동 경험을 데이터로 만든다.

OpenVLA와 Octo에 증류

OpenVLA는 LoRA, Octo는 전체 파인튜닝으로 흡수해 보지 못한 커넥터에도 일반화한다.

중요한 관찰

RL 롤아웃은 같은 개수의 성공한 인간 데모보다 파운데이션 모델 학습에 더 효과적이었다. RL 정책은 상태 변화에 반응하는 마르코프 정책의 경험을 제공하기 때문이다.

08 · RLT — RL Token

제너럴리스트의 관점을
스페셜리스트에게 건넨다

내부 표현 압축

π*0.6의 이미지 표현을 cross-attention 오토인코더로 1×2048 RL 토큰에 압축한다.

행동 의도까지 전달

RL actor·critic은 RL 토큰과 VLA가 제안한 액션 청크를 함께 입력받는다.

BC 정규화

더 좋은 행동을 아직 찾지 못했다면 기본 모델과 비슷하게 행동하도록 묶어 둔다.

직관

신입에게 무작정 탐색시키는 대신 베테랑이 “나는 지금 이렇게 보고, 이렇게 행동하려 한다”고 계속 알려준다. 신입은 모를 때 따라가고, 더 나은 해법을 발견했을 때만 벗어난다.

09 · Precision where it matters

긴 과제 전체가 아니라
가장 어려운 한 단계만

상위 정책이 장기 과제를 단계로 분해하고, 기본 모델을 먼저 실행한다. 나사 조이기·케이블 타이 끼우기·커넥터 삽입처럼 정밀도가 병목인 구간만 RL로 파인튜닝한다.

11 · The data dilemma

좋은 데이터만 쓸까,
실패까지 모두 쓸까?

Final policy only

깨끗하지만 작다

  • 모든 샘플이 좋은 행동
  • 단순 BC로 학습 가능
  • RL 중 수집한 대부분의 경험을 버림

Entire RL buffer

풍부하지만 지저분하다

  • 변동성·실수·복구를 모두 포함
  • 일반화와 회복력에 유리
  • 대부분은 품질이 낮은 행동
목표

좋은 데이터와 나쁜 데이터를 함께 학습할 수 있다면 별도 작은 actor 없이 로봇 파운데이션 모델 자체를 RL actor로 사용할 수 있다.

12 · CFGRL

Diffusion guidance를
정책 개선 연산자로

“좋은” 데이터 정책 πθ를 모든 데이터의 참조 정책 π̂에 가깝게 유지하면서 보상을 높이는 KL 정규화 목적함수:

J(πθ) = Eτ∼p(τ|πθ)[Σt γtr(st,at)] − βEs∼pπ[DKL(πθ(a|s) ‖ π̂(a|s))]

수렴 해는 advantage가 높은 행동을 지수적으로 강조한다.

π(a|s) ∝ π̂(a|s) · exp(A(s,a))1/β

Optimality variable

p(o|s,a) = f(A(s,a)) / Z(s)
π(a|s) ∝ π̂(a|s) · p(o|s,a)

Guided policy

π̂(a|s) · p(o|s,a)w

스코어 함수 분해와 베이즈 재배열을 거치면 정확히 CFG 형태가 된다. 핵심은 CFG가 별도 학습 알고리즘이 아니라 추론 시점의 정책 개선 방법이라는 점이다.

13 · Intuition

좋은 데이터의 모드로
더 세게 줌인한다

분포 수식 의미
Unconditional π̂(a|s) 좋은 것과 나쁜 것을 포함한 전체 경험
Conditioned π̂(a|s,o) 최적성 조건을 만족하는 분포
Guided π̂(a|s)p(o|s,a)w 좋은 행동의 중심부를 증폭
왜 AWR보다 안정적인가

AWR은 배치의 많은 샘플에 사실상 0의 가중치를 준다. CFGRL은 모든 샘플을 사용하면서 품질 조건과 guidance weight로 좋은 행동을 선택하므로 데이터 낭비가 적다.

16 · π0.7

원하는 행동을 프롬프팅

추론 시 상위 정책·월드 모델·원하는 메타데이터로 행동 특성을 선택.

17 · Takeaways

네 문장으로 정리하면

01

로봇 파운데이션 모델의 엔드투엔드 RL은 아직 큰 모델·샘플효율·어려운 과제를 동시에 만족하기 어렵다.

02

RL은 새로운 전략이 필요한 정밀 과제를 개별 스페셜리스트가 숙달하는 데 매우 잘 작동한다.

03

제너럴리스트는 RL 토큰과 행동 prior로 스페셜리스트의 탐색을 빠르게 만든다.

04

스페셜리스트의 롤아웃은 증류를 통해 제너럴리스트의 성능과 일반화를 끌어올린다.

18 · The flywheel

제너럴리스트 ↔ 스페셜리스트

스페셜리스트 부트스트랩

제너럴리스트의 표현과 기본 행동으로 복잡한 실제 과제를 빠르게 탐색한다.

실세계 숙련

작은 샘플효율 정책이 병목 과제를 높은 성공률과 속도로 숙달한다.

제너럴리스트로 재증류

성공·실수·복구 경험을 통합 모델에 넣고 다음 순환의 출발점을 높인다.

20 · Feynman explanations

어려운 개념을
일상 언어로

파운데이션 모델과 RL은 어떻게 다른가?
요리학교에서 온갖 요리의 기본기를 배운 사람과 자기 가게에서 김밥 하나를 만 번 말아본 사람의 차이다. 전자는 무엇이든 그럭저럭 하고, 후자는 김밥만 매우 빠르고 완벽하게 만든다. 좋은 로봇은 두 과정을 모두 거쳐야 한다.
RL 토큰은 무엇을 해주는가?
베테랑이 신입 옆에서 “지금 상황을 나는 이렇게 이해하고, 나라면 이렇게 행동하겠다”고 알려주는 압축된 힌트다. 신입은 처음부터 무작위로 헤매지 않고 합리적인 행동 근처에서 더 나은 방법을 찾는다.
Classifier-free guidance로 어떻게 RL을 하는가?
잘한 시도와 못한 시도 모두에 품질 스티커를 붙여 학습한다. 실행할 때 “잘된 스티커 쪽으로 더 강하게 움직여 달라”고 guidance weight를 높이면, 모델이 좋은 행동이 모인 중심부를 선택한다. 실패도 “이 방향은 아니다”라는 정보이므로 버리지 않는다.
왜 실세계에서 연습해야 하는가?
농구 자유투를 방 안에서 이미지 트레이닝만 해서는 실제 공의 무게와 체육관 바닥의 감각을 배울 수 없다. 시뮬레이터에서 잘하는 정책은 우선 시뮬레이터를 잘하는 정책이다. 마지막 정밀도는 실제 환경의 오차에서 배워야 한다.
21 · Q&A

로봇의 탐색은 왜
사람처럼 보이지 않는가?

Question

무작위 떨림 대신 구멍을 보고 다가갈 수 없나?

USB를 삽입할 때 사람은 목표를 보고 접근하지만 RL 정책은 궤적 전체에서 액션을 무작위로 흔드는 경우가 많다. play data나 world model이 필요한가?

Answer

제너럴리스트를 행동 prior로 사용하라

RLT의 BC 항처럼 모를 때는 파운데이션 모델과 유사하게 탐색하도록 한다. 기본 모델이 이미 많이 안다면, 참조 행동 근처는 매우 좋은 탐색 공간이다.

한 단계 더

액션 값을 무작위로 흔드는 대신 언어 입력을 바꾸며 의미 공간에서 탐색할 수 있다. “조금 비스듬히 접근해” 같은 의미적 변화는 원시 액션 노이즈보다 구조적인 탐색을 제공한다.

제너럴리스트는 탐색을 위한 훌륭한 행동 사전확률이다. 우리는 그것을 활용해야 한다.
