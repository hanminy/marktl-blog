모델과 학습 사이의 다리

검증 가능한 구조와 확장 가능한 학습은 반드시 경쟁해야 할까. Lujie Yang의 강연을 따라, 신경 Lyapunov 제어·PhysicsGen·OmniRetarget이 로봇 학습의 데이터 부족과 보증 부재를 어떻게 함께 다루는지 살펴본다.

Abstract

학습의 약점을 모델의 강점으로 감싸는 설계

이 강연의 핵심은 모델 기반 방법과 학습 기반 방법 사이에서 승자를 고르는 데 있지 않다. 모델 기반 방법의 구조·최적화·검증 가능성을 학습 기반 방법의 표현력·적응성·확장성과 결합해, 로봇 학습의 두 병목인 비싼 데이터와 성능 보증의 부재를 줄이는 데 있다. 발표자는 이를 세 사례로 논증한다. 신경 Lyapunov 제어는 안정성 위반 상태를 학습 데이터로 되돌리고, PhysicsGen은 소수의 인간 시연을 동역학적으로 가능한 접촉 궤적 분포로 확장하며, OmniRetarget은 사람·로봇·물체·지형 사이의 상호작용을 보존해 전신 로코-매니퓰레이션의 기준 모션을 정제한다.

로봇 제어의 오래된 대립은 선명하다. 모델은 계산과 검증에 강하지만 현실을 완벽하게 담기 어렵고, 학습은 복잡한 지각과 행동을 흡수하지만 데이터와 신뢰성에 큰 비용을 지불한다. 이 강연은 그 대립을 해소하기보다, 각 방법이 가장 잘하는 역할을 다시 배치한다.

Key Findings

먼저 읽는 다섯 가지 결론

1

모델은 정책의 대체재가 아니다

제약, 최적화, 반례 탐색, 형식 검증처럼 구조가 가장 중요한 경계에서 모델 기반 도구를 사용하고, 복잡한 표현과 적응은 학습 정책에 맡긴다.

2

데이터 품질이 학습 난도를 정한다

잘못된 기준 모션을 복잡한 보상으로 수선하기보다, 최적화로 기준 데이터 자체를 고치면 정책 학습과 sim-to-real 전이가 단순해진다.

3

보존해야 할 것은 상호작용이다

로코-매니퓰레이션에서는 관절 좌표의 일치보다 손–물체, 발–지면, 몸–지형의 상대적 관계가 과제 성공을 더 직접적으로 결정한다.

4

보증에는 적용 경계가 있다

완전한 Lyapunov 인증은 저차원·폐형식 동역학에서 설득력이 크다. 고차원 접촉 시스템에서는 정책 성능과 검증 확장성 사이의 절충이 필요하다.

5

다음 병목은 embodied fidelity다

인터넷 영상은 다양하지만 물리·접촉 정보가 거칠다. 저품질 대규모 원천을 고품질 로봇 궤적으로 바꾸고 시각 지각까지 연결하는 문제가 남는다.

01 / THESIS
Why Bridge?

대립이 아니라
역할 분담

접촉을 만들고 끊으며 이동과 조작을 함께 수행하는 로봇에는 정확한 계획과 유연한 적응이 동시에 필요하다. 강연은 “모델인가, 학습인가”라는 질문을 “어디에 무엇을 배치할 것인가”로 바꾼다.

펜 스피닝처럼 정교한 손 조작에서 물류 작업, 양팔 협응, 휴머노이드의 물체 운반으로 범위가 확장되면 문제의 성격도 달라진다. 로봇은 긴 시간 동안 여러 접촉 상태를 오가면서 균형을 유지하고, 물체와 환경의 불확실성에도 대응해야 한다.

  • 최적화와 검증이 가능하다
  • 모델 오차와 상태 추정에 민감하다

02 / GUARANTEE
Neural Lyapunov Control

인증서가 반례를
학습시킨다

첫 번째 다리는 보증이다. 제어기만 학습하는 대신 관측기와 Lyapunov 함수까지 공동 합성하고, 안정성 조건을 위반하는 상태를 다음 학습 데이터로 되돌린다.

목표는 완전한 상태를 직접 읽는 상태 피드백을 넘어, 비전이나 LiDAR 관측으로 내부 상태를 추정하는 출력 피드백 시스템까지 안정성을 인증하는 것이다. 신경망 제어기, 상태 관측기, Lyapunov 함수가 하나의 폐루프 안에서 함께 학습된다.

V(xt) > 0 V(xt+1) − V(xt) < 0 평형점 이외에서 양수이며 시간에 따라 감소하면, 상태는 평형으로 수렴한다.

학습 과정에서는 무작위 상태를 한 스텝 전개해 감소 조건 위반을 찾는다. 발견된 반례는 버퍼에 추가되고 제어기·관측기·Lyapunov 함수의 갱신에 사용된다. 마지막 단계에서는 샘플이 아니라 compact region 안의 무한히 많은 상태에 대해 완전 신경망 검증기를 적용한다.

왜 중요한가

  • 검증이 학습을 안내한다. 사후 검사에 머물지 않고 실패 상태를 능동적으로 공급한다.
  • 부분 관측을 포함한다. 제어기뿐 아니라 상태 추정 오차까지 폐루프 안정성 문제에 넣는다.
  • 보증의 범위를 넓힌다. 보수적인 부분수준집합을 넘어 더 큰 불변집합 인증을 지향한다.
  • 확장성의 한계도 분명하다. 폐형식 동역학과 완전 검증은 고차원 접촉 시스템에서 큰 비용이 된다.
03 / DATA
PhysicsGen

시연 하나를
물리적 분포로

두 번째 다리는 접촉이 풍부한 데이터 생성이다. 인간 시연은 긴 작업의 전역적 방향을 제공하고, 궤적 최적화는 그 주변에서 동역학적으로 실현 가능한 다양한 해를 만든다.

로봇 플릿과 원격조작자를 동원한 데이터 수집은 비싸고 느리다. 반면 기존 증강은 배경이나 외형을 바꾸는 시각적 변형에 집중해, 접촉 상태가 연속적으로 변하는 장기 조작 궤적의 물리적 타당성을 충분히 다루지 못했다.

Human Demonstration 소수의 VR 시연으로 긴 작업의 전역적 초기 추측을 얻는다.
Kinematic Retargeting 비관통과 관절 한계를 고려해 여러 로봇 embodiment로 옮긴다.
Trajectory Optimization 동역학과 입력 제약을 만족하도록 궤적을 수정한다.
Domain Variation 물성·초기조건·로봇 구성을 섭동해 데이터 분포를 확장한다.

증강의 단위는 이미지가 아니라 궤적이다

운동학적으로 그럴듯한 재생도 로봇의 관성, 구동 한계, 접촉 마찰, 물체 질량이 달라지면 실패할 수 있다. PhysicsGen은 시연 추종과 제어 노력의 균형을 목적함수로 두고, 비관통·관절 한계·동역학·입력 제약을 적용한다. 동역학은 폐형식 방정식이 아니라 시뮬레이터의 time stepping으로 처리할 수 있다.

7분 VR 장기 시연 수집 시간
24 원시 인간 시연
500 최적화로 증강한 궤적
핵심 해석: PhysicsGen의 성과를 단순한 데이터 개수 증가로 읽으면 중요한 점을 놓친다. 증강 데이터는 인간 시연의 의미적 구조를 유지하면서 로봇별 동역학과 접촉 제약을 만족한다. 정책이 분포 밖 상태에서 회복할 수 있었던 이유는 양뿐 아니라 물리적 커버리지에 있다.
04 / INTERACTION
OmniRetarget

좌표 대신
상호작용을 보존한다

세 번째 다리는 전신 로코-매니퓰레이션 데이터다. 사람과 로봇의 관절 위치를 단순히 맞추는 대신, 몸·물체·지형 사이의 상대적 기하 구조를 보존한다.

조작은 모방학습, 이동은 강화학습이라는 서로 다른 도구 사슬로 발전해 왔다. 두 영역을 결합할 때 기존 재표적화는 물체와 지면의 관통, 발 미끄러짐, 장면 상호작용 손실을 만들기 쉽다. 이후 RL 보상으로 문제를 수선하면 reward engineering이 길고 취약해진다.

Laplacian 좌표가 담는 것

각 꼭짓점의 Laplacian 좌표는 그 점과 주변 이웃의 상대적 변위를 표현한다. 사람 측 source mesh와 로봇 측 target mesh의 Laplacian 변형 차이를 최소화하면, 절대 좌표가 달라져도 손–물체와 발–지면의 배치가 비슷하게 유지된다. 접촉을 hard label로 직접 강제하지 않고 관계를 소프트하게 보존하는 셈이다.

한 시연을 공간·형상·로봇·지형으로 확장한다

물체의 위치와 회전, 3축 크기, 로봇 embodiment, 플랫폼의 높이와 깊이를 바꾸고 최적화를 다시 푼다. 증강은 명목 기준 주변에 단순 잡음을 추가하는 것이 아니라, 목적 조건마다 고품질 기준 모션을 새로 생성하는 과정이다.

세 접근이 학습 파이프라인에 삽입되는 위치
접근 주요 병목 모델 기반 도구 학습과의 연결 주요 경계
Neural Lyapunov 안정성 보증 부재 Lyapunov 조건, 완전 NN 검증 반례 유도 공동 학습 폐형식 동역학과 검증 확장성
PhysicsGen 접촉 데이터 부족 재표적화, 궤적 최적화, 제약 BC·diffusion policy용 데이터 시뮬레이터와 모델링 오차
OmniRetarget 전신 상호작용 손실 interaction mesh, Laplacian 최적화 imitation-guided RL 접촉의 소프트 근사

설계상의 의미

  • 좋은 데이터는 보상식을 줄인다. 기준 모션의 결함을 먼저 제거하면 ad hoc reward shaping이 감소한다.
  • 관계 표현이 embodiment 차이를 흡수한다. 절대 좌표보다 국소적 상호작용 구조가 체형 변화에 강하다.
  • 증강은 목적별 재해결이어야 한다. 단순한 잡음보다 새로운 조건에 맞춘 고품질 기준 모션이 넓은 전이를 만든다.
05 / VISION
Toward a General Framework

데이터 생성기를
학습법보다 위에 놓기

세 기여의 최종 목적은 개별 알고리즘을 넘어선 범용 데이터 생성 계층이다. 상류의 데이터 소스와 하류의 학습법 모두에 독립적인 변환기를 지향한다.

Teleoperation, MoCap, YouTube와 인터넷 영상에서 들어온 인간 행동을 OmniRetarget과 PhysicsGen으로 정제하고, 행동 복제·강화학습·인증서 유도 학습에 공급한다. 이 관점에서 최적화는 한 번의 계획을 실행하는 도구가 아니라, 대규모 학습을 위한 데이터 생산 인프라가 된다.

향후 2–3년의 연구 우선순위

질의응답에서 제시된 다음 단계는 세 갈래다. 첫째, MoCap보다 확장 가능한 인터넷·egocentric·tutorial video를 데이터 원천으로 활용하는 것. 둘째, 데이터의 양뿐 아니라 다양성·품질·물리적 fidelity를 함께 높이는 것. 셋째, 현재의 상태 기반 또는 시각 없는 proprioceptive 정책에 시각 지각을 통합하는 것이다.

실무자가 가져갈 원칙

  • 학습 실패를 먼저 데이터 실패로 의심하라. 보상과 모델 크기를 늘리기 전에 기준 궤적의 접촉·동역학 일관성을 검사한다.
  • 제약은 가능한 한 상류에서 적용하라. 관통과 미끄러짐을 후속 정책이 보상하게 만들지 않는다.
  • 검증기를 데이터 선택기로 활용하라. 실패 조건을 찾는 도구는 가장 정보량 높은 학습 샘플도 제공할 수 있다.
  • 절대 상태보다 과제 관계를 표현하라. embodiment 변화가 클수록 상호작용 중심 표현의 가치가 커진다.
  • 인지와 제어를 양방향으로 연결하라. 상위 계획은 하위 제어를 안내하고, 실행 결과는 다시 세계 모델을 갱신해야 한다.
06 / BOUNDARIES
Limits & Open Questions

보증과 확장의
경계선

세 접근은 모델 기반 구조가 학습을 강하게 만들 수 있음을 보여주지만, 각각의 성과는 분명한 전제와 실험 범위 안에서 읽어야 한다.

고차원 형식 검증

휴머노이드·사족보행까지 완전한 결정론적 인증을 확장하기는 어렵다. 정책 능력과 검증 가능성 사이에서 확률적·경험적 보증을 혼합할 필요가 있다.

동역학 표현의 차이

Neural Lyapunov 접근은 폐형식 동역학을 요구하지만 PhysicsGen은 시뮬레이터 time stepping을 사용할 수 있다. 두 접근의 적용 범위는 동일하지 않다.

접촉의 소프트 근사

OmniRetarget은 접촉을 hard constraint로 직접 표기하지 않고 Laplacian 변형 최소화로 암묵적으로 보존한다. 접촉 복잡도가 커질수록 근사의 한계를 검증해야 한다.

Sim-to-Real 오차

미모델링 충돌 형상, 상태 추정 오류, 마찰과 물성의 불확실성은 남는다. 다양한 증강 데이터가 회복성을 높이지만 오차를 제거하는 것은 아니다.

인터넷 영상의 물리 정보

영상은 규모와 의미 다양성이 크지만 깊이, 접촉력, 마찰, 가려진 신체 상태가 부족하다. 대규모 원천을 물리적으로 충실한 궤적으로 변환하는 과정이 핵심 난제다.

근거 자료의 해상도

본 보고서는 360p 프레임과 로컬 ASR에 기반한다. 판독하기 어려운 그래프 수치와 고유명사는 추측하지 않았으며, 프로젝트명과 수치는 화면 근거를 우선했다.

Reader’s Takeaway

좋은 로봇 학습은 더 많은 학습만으로 만들어지지 않는다

이 강연이 제시하는 가장 강한 메시지는 절충이 아니라 배치의 원리다. 모델은 제약을 세우고, 최적화는 데이터를 정제하며, 검증은 실패 상태를 찾는다. 학습은 그 위에서 복잡성을 흡수하고 새로운 환경에 적응한다. 데이터와 보증이 병목이 되는 순간, 문제는 모델과 학습 중 하나를 고르는 일이 아니라 둘 사이에 정확한 다리를 놓는 일이 된다.

Share-ready summary

모델과 학습 사이의 다리: Neural Lyapunov Control은 안정성 반례를 학습 데이터로, PhysicsGen은 소수 시연을 물리적으로 가능한 궤적 분포로, OmniRetarget은 인간 행동을 상호작용이 보존된 전신 로봇 모션으로 바꾼다. 로봇 학습의 다음 도약은 단순한 스케일링보다 데이터의 물리적 충실도와 검증 가능한 구조에서 올 수 있다.
