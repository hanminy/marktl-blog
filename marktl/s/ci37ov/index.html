한줄 요약

모방학습으로 만든 VLA를 실세계 강화학습으로 후속 학습시켜 에스프레소 제조 성공률을 40%에서 90% 이상으로 끌어올린 레시피(π*0.6)와, diffusion 정책을 안정적으로 온라인 미세조정해 평균 19.1분의 로봇 데이터로 30/30 성공을 달성한 EXPO-FT를 두 파트로 나누어 발표한다.

핵심 장면 분석

00:01:40 — 오늘 AI의 첫 번째 미해결 문제

Finn은 발표를 "현대 로봇 시스템에서 어떻게 높은 성능과 신뢰성을 동시에 달성할 것인가"라는 한 문장으로 연다. 높은 신뢰성은 로봇이 장시간 자율적으로 동작하기 위한 전제이며, 오늘날의 로봇과 사람을 가르는 핵심 차이라고 규정한다.

00:02:40 — 사람이 반복하는 루프의 한계

통상적 접근은 "목표 정의 → 데모 데이터셋 수집 → 최적화"이지만 첫 시도에 제대로 되는 법이 없다. 조금 나은 방법은 대학원생이나 엔지니어가 데이터를 더 모으고, 라벨을 더 상세하게 만들고, 실패 사례를 추가하며 반복하는 것이다. 문제는 사람이 먼저 지친다는 점이다. Finn은 여기서 "AI 시스템 자체가 반복하게 하자"는 발표의 논지를 끌어낸다.

00:04:50 — 대상 과제: 에스프레소 제조

에스프레소가 어려운 이유를 네 가지로 정리한다. 포터필터를 그룹헤드에 끼우는 정밀성, 돌려 잠그는 데 필요한 힘, 액체가 담긴 잔을 흘리지 않는 부드러운 조작, 그리고 추출이 끝나기 전에 다음 단계로 넘어가면 안 되는 타이밍 감각이다.

00:06:15 — VLA에 대한 기존 RL 연구와 미해결 지점

VLA 구조(사전학습 VLM + action expert)를 요약하고, 최근 2년간 VLA용 RL 레시피 연구가 다수 있었음을 짚는다. NVIDIA가 π₀를 RL로 미세조정해 GPU 삽입이라는 단기 과제를 높은 신뢰도로 해결한 사례를 든 뒤, 에스프레소처럼 길고 복잡한 과제에 대해서는 아직 설득력 있는 레시피가 없다고 문제를 좁힌다.

00:07:50 — 세 가지 핵심 설계 선택과 전체 파이프라인

레시피의 골격이 한 장에 담겨 있다.

  1. 정책 롤아웃과 사람의 교정(human policy corrections) 을 함께 배치로 사용한다. 데모에 없던 상태를 만났을 때 회복 방법을 스스로 알아내게 두는 대신 직접 보여주는 편이 효율적이기 때문이다.
  2. 진행도(progress to go) 를 예측하는 가치함수를 학습한다.
  3. advantage 조건부 지도학습으로 정책을 갱신한다.

00:10:00 — 가치함수가 학습한 "진행도"

가치함수는 사전학습 VLM에 value head를 얹어, 현재 이미지·언어 프롬프트·에피소드 메타데이터를 조건으로 성공까지 남은 시간(time to go) 을 예측한다. 몬테카를로 방식의 단순 지도학습 목적함수라 대형 모델·대규모 데이터로 확장하기 쉽다. 오른쪽 그래프가 근거다. 세탁물 접기에서 이미 접힌 옷을 다시 펼치면 가치가 하락(음의 진행)하고, 회복하면 다시 상승한다. 아래 냉장고 사례에서도 손잡이를 놓치면 진행이 없고, 문을 열면 크게 오르며, 정수 필터를 넘어뜨리면 음의 진행으로 잡힌다. 진행도 개념이 목적함수에서 자연히 창발한다는 점이 핵심이다.

00:10:50 — advantage 추정과 이진화

advantage는 행동 전후 가치의 차이로 계산한다. 이 델타가 임계값을 넘으면 양의 advantage, 아니면 음의 advantage로 이진화해 정책의 조건 입력으로 넣는다. 테스트 시에는 양의 advantage로 조건화해 전진하는 행동만 선택하게 만든다. 학습에는 원본 데모뿐 아니라 반복 과정에서 쌓인 롤아웃과 DAgger 데이터가 함께 쓰인다.

00:12:30 — 사람과 협업하는 라떼 제조

학습된 정책의 실제 동작(8배속). 포터필터를 그라인더 아래에 놓고, 탬핑하고, 삽입하고, 추출을 기다린 뒤, 사람이 스팀한 우유를 붓는다. Finn은 가장 어려운 구간으로 완성된 잔을 코스터로 옮기는 마지막 동작을 꼽는다. 작은 흔들림 하나로도 크게 쏟기 때문이다.

00:13:40 — 13시간 연속 운전

신뢰성의 증거로 제시된 장면이다. RL 후속 학습을 거친 정책으로 13시간 동안 커피를 계속 만들었고(100배속 타임랩스), 모방학습만으로 만든 초기 정책보다 훨씬 안정적이었다고 보고한다.

00:14:10 — Dandelion 초콜릿 공장의 실제 워크플로

연구용으로 지어낸 과제가 아니라는 점이 중요하다. Physical Intelligence 사무실 근처 Dandelion 초콜릿 공장에서 사람이 실제로 반복하는 작업(골판지 상자 조립·라벨링·적재)을 그대로 가져와 재현했다(80배속, 실제 10분 51초).

00:14:45 — 처음 보는 옷, 처음 보는 집

일반화가 필요한 워크플로 검증. 로봇이 한 번도 본 적 없는 옷을, 한 번도 가본 적 없는 집에서 접는다. 동일한 알고리즘이 이 설정에도 적용된다는 것을 보인다.

00:15:30 — 성공률이 아니라 throughput

Finn은 로보틱스 실험에서 잘 논의되지 않는 지표를 강조한다. 성공률과 속도를 동시에 담기 위해 단위 시간당 성공 횟수(throughput) 를 측정한다. 실패하면서 시간까지 오래 끄는 정책은 이 지표에서 크게 불리해진다.

00:16:40 — advantage 조건화가 AWR·PPO를 앞선다

정량 결과의 핵심. 네 과제 평균 throughput 2배 향상이며, 에스프레소는 40% → 90% 이상의 성공률로 올라섰다. 다른 RL 기반 정책 추출 방식과 비교하면 이 설정에서 AWR과 PPO는 SFT 대비 개선이 없었고, advantage 조건화만이 더 높은 성공률과 훨씬 높은 throughput을 냈다.

00:18:20 — 2부: 온라인 미세조정 문제 정의

Perry Dong이 이어받아 데이터 효율에 초점을 맞춘다. 목표는 π_VLA를 추가 온라인 데이터로 개선하는 것이고, 관측은 손목·측면 카메라의 다중 시점 RGB와 고유수용성 상태다. 갱신은 과제 요구에 따라 스텝 단위, 에피소드 단위, 배치 단위로 수행한다.

00:19:50 — diffusion 정책이 RL과 잘 안 맞는 이유

현대 VLA는 대부분 diffusion/flow matching 같은 표현력 높은 정책을 쓰는데, 전통적 심층 RL은 단순한 가우시안 정책을 전제로 설계되었다. 기존 시도는 세 갈래다. 가치를 diffusion으로 직접 역전파(긴 denoising 체인 탓에 불안정), 여러 액션을 뽑아 Q가 최대인 것 선택, denoising 과정 자체를 가치로 유도. 뒤 두 방식은 정책 자체가 가치를 최대화하도록 갱신되지 않아 성능을 남긴다.

00:20:40 — EXPO 아이디어 1: 작은 edit policy

표현력 높은 base diffusion 정책을 직접 가치 최대화로 학습시키는 대신, 그 위에 작은 edit policy를 얹는다. edit policy는 가우시안이라 검증된 off-policy 목적함수를 그대로 쓸 수 있고, base 정책은 오프라인·온라인 데이터에 대한 안정적인 지도학습으로 계속 유지한다.

00:22:00 — EXPO 아이디어 2: on-the-fly 샘플링

edit policy가 Q 함수에 뒤처지거나 붕괴하는 문제를 샘플링으로 흡수한다. base에서 여러 액션을 뽑고, 각각에 대해 edit을 여러 개 뽑은 뒤, 합친 집합에서 Q가 가장 높은 것을 고른다. 항상 최신 Q를 쓸 수 있고, base 액션이 후보에 남아 있어 edit 붕괴에도 강하다. 벨만 백업의 다음 액션 선택에도 같은 절차를 쓴다.

00:23:00 — 12개 벤치마크 실험 설정

조작·내비게이션·손재주를 아우르는 12개 벤치마크에서, 오프라인 데이터셋을 시드로 두고 sparse reward로 평가한다. EXPO는 안정적이고 효율적인 미세조정과 최고 수준 성능을 보였다. 다만 오프라인 데이터 범위를 크게 벗어나는 탐색이 필요하면 저조하다(relocate binary). 실세계에서는 데모 몇 개를 더 모으는 편이 대개 현실적이라고 부연한다.

00:25:00 — EXPO-FT: 액션 청킹과 사람 개입

EXPO의 안정성·효율성 위에 action chunking과 human-in-the-loop 보정을 얹은 것이 EXPO-FT다. 온라인 정제 단계에서 사람이 지켜보다가 언제든 원격조작으로 개입할 수 있고, 정책의 자율 예측과 사람이 덮어쓴 행동이 모두 리플레이 버퍼에 들어간다. 보상은 규칙 기반 분류기의 sparse binary 신호를 써서 과제별 보상 설계 부담을 피한다.

00:26:00 — 19.1분으로 30/30

π₀.₅를 미세조정해 여섯 과제 모두 30/30을 달성했고, 소요된 온라인 로봇 데이터는 평균 19.1분이다. 과제는 전구 배선·점등, 당구공 포켓에 넣기, 와인병에 꽃 꽂기, 사탕 퍼담기, 넓은 초기 상태에서 큐브 집기, 계란 뒤집기로 정밀성·동적 동작·초기 상태 다양성을 아우른다. Hindsight Experience Replay 같은 강력한 실세계 기법도 초기 상태 분포를 크게 넓히면 일관된 성능을 내지 못했다고 비교한다.

00:28:45 — 남은 문제: 계산 비용

여러 액션 후보를 샘플링해 최선을 고르는 절차는 일종의 RL판 test-time scaling이지만 계산 비용이 크다. 이미 허용 가능한 지연 한계 근처에서 동작하는 현대 VLA 같은 대형 모델에 특히 부담이다. 해법으로 denoising이 끝나기 전에 후보를 미리 걸러내는 접근(FASTER)을 제시하며, 이 필터링 자체를 MDP로 보고 적응적 정책을 학습한다.

00:30:20 — 향후 방향

세 갈래를 제시한다. 사전학습으로 강건성을 더 끌어올릴 수 있는가(π₀.₇ 사례), 과제마다 규칙 기반 보상 분류기를 만드는 대신 일반화 가능한 보상 모델을 학습할 수 있는가(Robot Reward Model 리더보드), 메모리와 추론이 신뢰성에 기여하는가(Mem 논문 — 50분 길이의 장기 메모리가 필요한 과제 수행, in-context 적응에도 유리).

주요 내용 요약

핵심 포인트

  • 모방학습만으로는 첫 시도에 신뢰성 있는 정책이 나오지 않으며, 사람이 데이터를 반복 개선하는 루프는 사람의 체력에서 먼저 한계에 부딪힌다. 반복 주체를 AI로 옮기는 것이 발표 전체의 논지다.
  • 신뢰성의 정의를 throughput(단위 시간당 성공) 으로 잡은 것이 방법론상 중요하다. 성공률만 보면 느리게 성공하는 정책이 과대평가된다.
  • 1부(π*0.6)의 결론: 진행도 예측 가치함수 + advantage 이진화 조건부 지도학습으로 throughput 2배, 에스프레소 성공률 40% → 90%+.
  • 이 설정에서 AWR과 PPO는 SFT 대비 개선이 없었다. 표준 RL 목적함수를 그대로 가져오는 것이 능사가 아니라는 실증이다.
  • 2부(EXPO/EXPO-FT)의 결론: base diffusion 정책은 지도학습으로 안정적으로 두고, 작은 edit policy와 on-the-fly 샘플링으로 가치를 최대화하면 19.1분의 온라인 데이터로 30/30이 가능하다.
  • 검증 과제가 연구용 벤치마크가 아니라 실제 상업 워크플로(초콜릿 공장의 상자 작업, 13시간 카페 운전)라는 점이 이 발표의 차별점이다.

기술적 내용

  • 가치함수: 사전학습 VLM + value head. 입력은 현재 이미지, 언어 프롬프트, 에피소드 메타데이터. 출력은 성공까지 남은 시간. 몬테카를로 지도학습이라 확장성이 좋다.
  • advantage 조건화: A(o,a) = V(이후) − V(이전). 임계값으로 이진화해 정책 입력에 넣고, 추론 시 양의 값으로 조건화한다. 연속값 조건화는 Q&A에서 "시도하지 않았고 흥미로운 방향"이라고 답했다. 이진화의 실용적 이점은 테스트 시 조건값을 고르기 쉽다는 점이다.
  • 학습 데이터 구성: 원본 데모 + 정책 롤아웃 + 사람 교정(DAgger). 사람 교정이 회복 행동의 커버리지를 메운다.
  • EXPO: base(diffusion/flow) + edit(가우시안)의 2단 구조. 표현력은 base가, 가치 최대화는 edit이 담당한다.
  • on-the-fly 샘플링: {a₁…aₙ, ā₁…āₙ} 중 Q 최대 선택. 벨만 백업의 next action 선택에도 동일 적용.
  • EXPO-FT: EXPO + action chunking + 원격조작 개입. sparse binary reward(규칙 기반 분류기).
  • FASTER: denoising 완료 전 후보 필터링을 MDP로 정식화. implicit diffusion Q-learning 등 "샘플 후 최선 선택" 계열 전반에 적용 가능.

시사점과 한계

한계 (발표에서 직접 밝힌 것)

  • 완전 자율이 아니다. 개입 데이터 수집과 환경 리셋에 사람이 계속 필요하다. 특히 EXPO-FT는 과제마다 사람이 리셋을 수행한다.
  • 반복 횟수가 몇 회에 그쳤다. 더 많이 돌리면 신뢰성이 더 오를 여지가 있다는 뜻이기도 하다.
  • 로봇은 여전히 실수하며 사람보다 느리다.
  • 수십억 파라미터 모델의 온라인 미세조정은 계산 비용이 크다.
  • EXPO는 오프라인 데이터 분포를 크게 벗어난 탐색이 필요한 과제에서 약하다.

현장 적용 관점에서의 시사점

  • 진행도 기반 가치함수는 도메인 이식성이 높아 보인다. "성공까지 남은 시간"은 과제별 보상 설계 없이 지도학습으로 얻어지며, 굴착·상하차처럼 공정 단계가 뚜렷한 작업에서는 오히려 정의하기 쉬운 신호다. 되돌아가는 동작에 음의 진행이 잡히는 성질도 반복 작업 평가에 유용하다.
  • 사람의 교정을 학습 신호로 흡수하는 구조가 숙련 오퍼레이터가 있는 현장과 잘 맞는다. 데모를 새로 모으는 대신, 자동 운전 중 개입한 순간이 그대로 학습 데이터가 된다.
  • throughput 지표는 장비 운용 KPI와 직접 연결된다. 성공률 대신 시간당 처리량으로 목표를 세우면 연구 지표와 현장 지표의 간극이 줄어든다.
  • 다만 이 결과는 모두 테이블탑 매니퓰레이션이다. 중장비는 액추에이터 지연, 지형 변화, 안전 정지 요건이 달라 개입 기반 온라인 RL을 그대로 옮기기 어렵다. 특히 "사람이 언제든 원격조작으로 덮어쓴다"는 전제가 중장비 안전 규정과 충돌할 수 있다.
  • 계산 비용 문제는 현장에서 더 심각하다. 후보 샘플링 방식은 지연에 민감한 제어 루프와 상충하므로, FASTER 계열의 조기 필터링이 오히려 중장비 쪽에서 더 중요해질 수 있다.
