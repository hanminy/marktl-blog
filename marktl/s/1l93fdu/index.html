멈추면 안정적일 것이라는 직관을 정지 마찰이 뒤집는다. 압력과 IMU로 ‘빈 버킷의 토크’를 학습하고, 남는 토크에서 적재량을 읽어낸 13 t급 굴착기 연구.

선택한 동적 구간의 적재량 오차 0.26–4.62%

318·618 kg 시험에서 링크 속도 2 °/s 이상인 5초 구간을 사용한 결과. 전체 작업 구간의 정확도를 뜻하지는 않는다.

원 연구 Mehmet Ferlibas · Reza Ghabcheloo 소속 Tampere University, Finland 발표 SICFP’21 · 2021 노트 작성 2026.09.25
ABSTRACT

연구 초록

제조사의 질량·관성 자료 없이 굴착기 버킷의 적재량을 추정할 수 있을까? 이 연구는 관절 토크를 자세·운동 함수와 묶음 파라미터의 선형식으로 표현하고, 무부하 데이터에 최소제곱을 적용한다. 이후 실측 토크에서 무부하 모델의 예측값을 빼 하중을 추정한다. 정적 계량의 MAPE는 9.42–13.98%였고, 선택한 동적 구간의 적재량 오차는 0.26–4.62%였다. 핵심은 동역학을 포함하는 것뿐 아니라, 마찰의 영향이 큰 정지 구간을 어떻게 다루느냐에 있다.

먼저 읽는 세 가지 발견

01 / MODEL

개별 물성 대신
식별 가능한 조합을 찾는다

질량과 무게중심을 각각 구하려 하지 않는다. 토크식에 함께 나타나는 중력 파라미터 6개와 관성 파라미터 3개를 추정한다.

02 / SIGNAL

버킷 토크보다
붐−스틱 토크 차가 낫다

정적 검증에서 τ₂₃의 토크 예측 MAPE는 8.31%. 버킷 토크 τ₄의 40.98%보다 작아 적재량 추정에 채택됐다.

03 / CONDITION

정확도는
측정 구간에 달려 있다

속도 조건을 둔 동적 구간에서 낮은 오차를 얻었다. 정지 구간을 포함하면 오차가 다시 커질 수 있었다.

01 / THE PROBLEM

저울 없이, 작업을 끊지 않고

굴착기가 퍼 올린 흙을 덤프트럭에 실을 때 버킷마다 적재량을 알 수 있다면, 과적을 막고 생산량을 자동으로 집계할 수 있다. 문제는 실린더 압력에 흙의 무게만 담겨 있지 않다는 점이다. 붐·스틱·버킷 자체의 무게와 관성도 같은 압력 신호를 만든다.

따라서 먼저 알아야 할 것은 “이 자세와 움직임에서 빈 버킷이라면 얼마의 토크가 필요한가?”다. 연구는 제조사 물성 자료 대신 실측 데이터에서 이 기준 모델을 식별한다.

기존 접근과 이 연구가 다루는 공백
접근한계와 과제
정지 자세 계량측정을 위해 작업 흐름이 끊기고, 정지 마찰이 압력에 남아 오차를 만든다.
휠로더 동적 계량Hindman(2008), Ballaire(2015) 등의 접근을 굴착기의 3관절 구조에 그대로 적용하기 어렵다.
소형 굴착기 식별Tafazoli(1996) 등과 비교할 때, 큰 기체에서는 정지 마찰의 영향을 더 주의해서 다뤄야 한다.

연구의 기여는 토크식을 분리된 선형 회귀 형태로 정리하고, 같은 기체에서 정적·동적 모델을 비교했다는 데 있다. 특히 붐 토크와 스틱 토크의 차이 τ₂₃ = τ₂ − τ₃를 유용한 계량 신호로 선택한다.

STEP 01 압력 → 실린더 힘

양쪽 챔버의 압력에 각 유효 면적을 곱한 뒤 차를 구한다.

STEP 02 힘 → 관절 토크

실린더 길이와 관절각의 관계에서 기계적 이득을 계산한다.

STEP 03 토크 차 → 적재량

실측 토크와 무부하 예측 토크의 차이를 하중으로 환산한다.

PRESSURE TO TORQUE
F = P₁A₁ − P₂A₂
τ = FJ,   J = dz / dθ

P는 압력, A는 챔버의 유효 면적, z는 실린더 길이, θ는 관절각이다.

BOOM GEOMETRY / 식 8
q₂ = β₁ + β₂ + θ₂
z₂ = √(L₁₁² + L₁₂² − 2L₁₁L₁₂ cos q₂)
Jbo = dz₂ / dθ₂ = L₁₁L₁₂ sin q₂ / z₂

직관으로 읽기. 실린더가 dz만큼 늘어나며 한 일 F·dz와 관절이 dθ만큼 회전하며 한 일 τ·dθ는 같다. 그래서 토크는 힘에 dz/dθ를 곱한 값이다.

03 / STATIC IDENTIFICATION

질량을 하나씩 구하지 않아도
중력 토크는 예측할 수 있다

정지 상태를 설명하는 모델에는 중력 항만 둔다. 이때 토크에 나타나는 질량과 무게중심의 조합을 여섯 개의 묶음 파라미터로 정리하면, 비선형처럼 보이던 물성 추정 문제를 선형 회귀로 풀 수 있다. 실제 측정값에 남는 마찰은 이 모델에 포함되지 않는다.

SIX GRAVITY PARAMETERS / 식 6·7
τ = g Y(Θ) πs
  • πs1 = Mbur₄ cos α₄
  • πs2 = Mbur₄ sin α₄
  • πs3 = Mbua₃ + Mstr₃ cos α₃
  • πs4 = Mstr₃ sin α₃
  • πs5 = (Mbu + Mst)a₂ + Mbor₂ cos α₂
  • πs6 = Mbor₂ sin α₂

bo·st·bu는 각각 붐·스틱·버킷을 뜻한다. aᵢ는 알려진 링크 길이, Θ는 링크 각도 모음이다. 모든 중력 묶음 파라미터의 단위는 kg·m이다.

여러 자세의 측정값을 쌓으면 최소제곱으로 파라미터를 구할 수 있다. 중력가속도의 포함 여부를 명확히 하기 위해 아래에서는 설계행렬을 X = gY로 쓴다.

LEAST SQUARES / 식 9의 회귀 형태
π̂s = (XTX)−1XTτ

여러 자세의 행을 쌓은 X가 충분한 열 계수를 가질 때의 표현이다. 정적 식의 g를 X에 포함해 표기를 통일했다.

직관으로 읽기. 토크에서는 질량과 무게중심이 곱으로 나타난다. 링크별 M·r·α를 각각 분리해 구하는 대신, 관측 가능한 여섯 조합을 구하면 중력 토크를 예측할 수 있다.

04 / DYNAMIC IDENTIFICATION

움직임을 설명하는 데
관성 묶음 세 개를 더한다

움직이는 링크에는 중력뿐 아니라 관성·원심·코리올리 항이 작용한다. 이 항들을 포함해도 모델은 파라미터에 대해 선형으로 정리된다. 전체 3관절 모델은 3×9 회귀행렬과 파라미터 9개로 표현된다.

DYNAMIC REGRESSION / 식 14·16
τ = Y(Θ, Θ̇, Θ̈) π
  • πd1 = Ibu + Mbur₄²
  • πd2 = Ist + Mstr₃² + Mbua₃²
  • πd3 = Ibo + Mbor₂² + (Mst + Mbu)a₂²

I는 링크 무게중심 기준 관성모멘트다. 동적 회귀행렬에는 중력 항도 함께 포함된다.

τ₂₃만 쓰면 더 작아진다. 붐−스틱 토크 차를 설명하는 식에는 관성 묶음 πd3 하나와 중력 묶음 여섯 개, 총 7개 파라미터가 필요하다. 관성 역시 질량·거리와 결합한 형태로 식별된다.

가속도는 센서 대신 스플라인에서

각가속도를 직접 측정하지 못했기 때문에 각도 시계열에 매끄러운 스플라인을 적합하고 미분했다. 스플라인에서 얻은 각속도와 IMU 각속도의 RMSE는 붐 0.33, 스틱 0.35, 버킷 0.34 °/s였다. 이는 각속도 일치도를 보여주는 결과이며, 각가속도의 정확도나 실시간 구현을 직접 입증하는 값은 아니다.

05 / PAYLOAD ESTIMATION

정확도를 바꾼 것은
‘어느 구간을 읽는가’였다

동적 적재량 추정에서는 버킷 무게중심이 하중에 따라 변하지 않는다고 가정한다. τ₂₃ 모델의 Mbu를 Mbu + M̂로 바꾸고, 추가된 질량 M̂에 대해 푸는 방식이다.

이 단계에서는 묶음 파라미터만으로 충분하지 않다. 버킷 무게중심의 거리 r₄와 각 α₄가 필요하므로, 연구는 이미 알고 있는 버킷·틸트로테이터 질량 750 kg을 사용해 두 값을 되돌려 구한다.

RECOVERING THE BUCKET CENTER OF MASS / 식 22·23
α₄ = tan−1(πs2 / πs1)
r₄ = πs1 / (Mbu cos α₄)

묶음 파라미터에서 개별 무게중심 정보를 복원하려면 별도의 질량 정보가 필요하다.

정지 마찰이 다시 측정에 들어온다.

연구 결과의 의미를 요약한 편집 문장 · 원문 직접 인용 아님

정지 구간을 포함하면 일부 시험에서 오차가 크게 늘어난다. 연구가 시사하는 것은 운동 중 계량의 가능성과 함께, 계량에 적합한 구간을 고르는 로직의 중요성이다.

“빠를수록 무조건 정확하다”는 결론은 아니다

좋은 결과는 속도 조건을 충족하는 특정 5초 구간에서 얻었다. 속도 증가에 따라 정확도가 계속 좋아진다는 관계나, 모든 굴착기에 2 °/s가 최적이라는 사실을 입증한 실험은 아니다. 정적·동적 실험의 하중도 달라 오차 비율만으로 개선 배수를 단정하기 어렵다.

06 / LIMITS & IMPLICATIONS

실험실의 가능성과
현장 계량 사이에 남은 것

연구의 한계와 적용 시 확인할 조건
현재 한계실용화에 주는 의미
마찰 모델 부재데이터에 남은 마찰이 특히 정지 구간을 오염시킨다. 마찰 보상 또는 계량 구간 선별이 중요하다.
무게중심 고정 가정콘크리트 블록의 위치가 가정과 어긋날 수 있다. 실제 적재물에서도 분포 변화의 영향을 확인해야 한다.
각가속도의 후처리스플라인 미분에 의존한 결과다. 실시간 계량을 위해서는 온라인에서 쓸 수 있는 가속도 측정·추정 방법이 필요하다.
수직면 3관절 한정캐빈 선회나 틸트로테이터 동작을 포함한 작업 정확도는 이 모델의 검증 범위 밖이다.

향후 방향으로는 각가속도 측정을 통한 실시간 구현과 크레인 등 다른 기계로의 확장이 제시된다. 현장 적용 관점에서는 모델 식별만큼 센서 신호의 품질, 적재물 분포, 유효한 계량 자세·구간을 함께 설계하는 일이 중요하다.

수식에서 읽을 수 있는 추가 조건도 있다. 정적 추정식의 분모 g a₂ cos θ₂가 작아지는 자세에서는 같은 토크 오차가 더 큰 질량 오차로 증폭될 수 있다. 이는 식에 근거한 해석이며, 별도의 실험 결과를 뜻하지 않는다.

07 / APPLICATION NOTE
노트 작성자의 해석 · HR35에서 별도 검증 필요

HR35에 가져갈 것은
숫자보다 검증 방법이다

제공된 노트에 따르면 HR35도 링크 각도와 실린더 양쪽 압력을 사용한다. 센서 구성의 공통점은 이 접근을 검토할 근거가 된다. 다만 이 연구의 센서는 IMU이고 HR35는 20 Hz 경사계이므로, 동적 신호의 품질과 미분 가능성은 별도로 판단해야 한다.

  • 압력 count를 물리 단위로 보정한다

    HR35 압력이 아직 count 단위라면 bar 또는 Pa 환산이 먼저다. 압력·면적·길이의 단위를 맞춰야 토크 모델과 비교할 수 있다.

  • 디지털 트윈을 묶음 파라미터로 비교한다

    트윈의 M·r·α에서 중력 묶음 6개를 계산하고 실차 식별값과 대조한다. 관성 정보까지 포함하면 6+3 구조로 모델을 점검할 수 있다.

  • τ₂₃를 우선 후보로 검증한다

    버킷 축의 작은 압력 신호에 마찰이 크게 작용했다는 결과는 참고할 만하다. HR35에서도 τ₂₃와 다른 토크 신호의 검증 오차를 비교한 뒤 선택한다.

  • 2 °/s를 초기 시험 조건으로 둔다

    바로 고정할 계량 기준보다는 검증할 출발점이다. HR35의 속도·자세별 오차를 확인해 계량 구간의 문턱을 정한다.

  • 20 Hz 각도 신호의 미분 문제를 먼저 푼다

    각가속도 추정은 특히 민감할 수 있다. 원 노트는 Werner(2025)의 IMU 가속도 활용과 ISARC(2002)의 여과 회귀를 대안으로 언급하며, 두 접근은 원문을 확인한 뒤 비교할 필요가 있다.

  • 버킷 실측 질량을 확보한다

    같은 방식으로 r₄·α₄를 복원하려면 버킷 질량이 필요하다. 노트의 ‘실차 자료 요청 C 항목’과 연결되는 선행 자료다.
