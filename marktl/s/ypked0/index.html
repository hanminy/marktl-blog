건설 현장에서 암석 하나를 버킷으로 들어 올리는 일은 단순해 보인다. 그러나 로봇에게는 불규칙한 형상, 변화하는 토양 저항, 가림, 유압 지연을 한꺼번에 풀어야 하는 복합 조작 문제다. ETH Zurich와 Gravis Robotics 연구진은 이 문제를 정밀한 3D 복원이나 전용 그리퍼 없이 풀어냈다.

Abstract · 한 문장 요약

12톤 유압 굴착기가 표준 버킷, 암 상태 피드백, 암석당 20개의 LiDAR 점만으로 불규칙 암석을 정렬·퍼담기·인양하도록 강화학습한 결과, 현장 40회 시험에서 70% 성공률을 달성했다. 약 300시간의 숙련도를 지닌 인간 운전자의 성공률은 83%였다.

01 · Key findings

이 연구에서 먼저 기억할 네 가지

  • 전용 도구 없이 암석을 조작했다 작업 중 그리퍼로 교체하지 않고, 토사 굴착에 쓰는 표준 버킷으로 0.4–0.7m 암석을 제거했다.
  • 지각 입력은 놀랄 만큼 작다 SAM2로 목표 암석을 추적한 뒤, 마스킹한 LiDAR 점 중 20개만 정책에 전달한다.
  • 토양 대응 전략이 창발했다 경질 토양에서는 표면을 길게 끌고, 연질 토양에서는 직접 관입하는 행동을 별도 분류기 없이 학습했다.
  • 남은 병목은 정책보다 관측이다 작은 암석이 버킷 뒤로 가려질 때 추적이 끊기며, 실제 토양 동역학과의 차이도 성능을 제한했다.

02 · Problem & contribution

토사를 퍼는 것과 암석 하나를 집는 것은 다른 문제다

기존 자동 굴착 연구는 주로 토사나 자갈처럼 연속 매질로 근사할 수 있는 재료를 다뤘다. 개별 암석을 대상으로 한 연구는 정밀한 3D 모델과 전용 그리퍼에 의존하는 경우가 많았다. 하지만 실제 현장에서 도구 교체는 작업 흐름을 멈추며, 암석을 치운 다음에는 다시 버킷이 필요하다.

이 연구의 핵심은 암석 제거를 단순한 “굴착량 최대화”가 아니라 정렬 → 퍼담기 → 컬링 → 인양으로 이어지는 물체 조작 문제로 다룬 데 있다. 정책은 목표 암석의 자세와 토양 저항에 반응하며 버킷의 접근 깊이와 방향을 계속 수정한다.

많이 퍼는 궤적만으로는 암석을 안정적으로 포획할 수 없다. 필요한 것은 암석의 상태에 반응하는 조작 정책이다.

시뮬레이션 기준선 비교에서 도출되는 핵심 메시지

연구가 결합한 세 가지 요소

  1. 표준 버킷 기반 개별 물체 조작: 암석을 버킷 정면에 맞추고, 아래로 진입해 퍼담은 뒤, 버킷을 말아 올리며 고정한다.
  2. 희소 지각: RGB 영상에서 SAM2로 목표 암석을 분할하고 LiDAR 점군을 마스킹한 뒤, 표면점 20개만 정책에 입력한다.
  3. 토양 적응형 제어: 토양 종류를 명시적으로 판별하지 않고도 관절 토크와 운동 상태를 이용해 관입 전략을 바꾼다.
저자들의 기여 주장

저자들은 이 연구를 표준 굴착 버킷과 희소 3D 지각을 사용해 산업 규모 건설 장비에서 암석 조작을 현장 검증한 첫 사례로 제시한다.

04 · Simulation & learning

단순한 토양 모델로 8년의 경험을 압축하다

실제 굴착기로 시행착오를 반복하는 것은 느리고 위험하며 장비 비용도 크다. 연구진은 Isaac Lab에서 수천 개 환경을 병렬 실행하고, 실제 유압 지연과 토양 물성을 무작위화해 정책이 특정 조건에 과적합하지 않도록 했다.

굴착기·암석·토양 모델

  • 굴착기: 베이스 회전, 붐, 스틱, 텔레스코픽 연장, 버킷 피치의 5개 관절을 작동시킨다.
  • 암석: 실제 암석을 3D 스캔한 50개 형상을 사용한다. 밀도는 2,500kg/m³이며 질량은 에피소드마다 ±10%로 무작위화한다.
  • 암석 크기: 주축별 범위는 각각 0.3–1.0m, 0.1–0.5m, 0.2–0.7m다.
  • 접촉: 암석–토양 마찰계수는 0.35–0.6, 굴착기 지지면 마찰계수는 0.8이다.
  • 토양: Reece의 Fundamental Equation of Earth-Moving에 기반한 준정적 2D 저항 모델을 사용한다.
모델링 선택의 의미

입자 기반 토양 시뮬레이션보다 물리적 충실도는 낮지만 계산량이 훨씬 작다. 이 선택 덕분에 대규모 병렬 환경에서 강화학습을 수행할 수 있었다.

정책은 무엇을 보고 무엇을 명령하는가

상태에는 관절 위치·속도·토크, 회전 관절 이력, 버킷 자세와 속도, 목표 암석의 20개 3D 점, 이전 행동이 포함된다. 모든 입력은 −1에서 1 사이로 정규화되며, 출력은 다섯 관절의 속도 명령이다.

(1) at = [q̇turn, q̇boom, q̇stick, q̇tele, q̇pitch]T

정렬을 마친 뒤에는 회전축을 멈춰 작업을 수직 평면에 가깝게 제한한다. 이를 위해 회전 명령의 절댓값이 임계값보다 작으면 0으로 만드는 데드밴드를 사용한다.

(2) q̇turn = { 0, if |q̇turn| < εturn;  q̇turn, otherwise }

실제 유압계의 지연은 에피소드마다 0–1.2초 범위에서 샘플링한다. 정책의 이력 길이는 가장 긴 지연 구간을 덮도록 설정해, 현재 관측만으로 파악하기 어려운 유압 응답을 시간 문맥으로 보완한다.

보상과 종료 조건

보상은 횡방향 정렬, 버킷 접근, 암석 아래 진입, 버킷 내부 포획, 컬링, 목표 높이 인양, 최종 성공을 순차적으로 유도한다. 급격한 행동, 과도한 버킷 속도, 불필요한 회전, 토양 내부 회전, 얕고 정렬되지 않은 퍼담기와 최종 실패에는 벌점을 준다.

암석이 버킷 안에 있고 컬 각도가 0.5rad보다 크며 기준면에서 0.5m 이상 들리면 성공이다. 제한시간은 29초다. 베이스 또는 버킷의 과속, 관절 속도 제한 위반, 암석 낙하, 잘못된 받음각도도 에피소드를 종료한다.

05 · Evidence

시뮬레이션 94%, 실제 현장 70%

시뮬레이션: 토사 굴착 정책과의 격차

  • 94% 제안 방법의 전체 시뮬레이션 평균 성공률. 연속 토사 굴착용 Digging RL 기준선은 33%였다.
  • 88% 가장 어려운 대형 암석·경질 토양 조건의 성공률. 같은 조건에서 기준선은 0%였다.
  • 87% 학습에 사용하지 않은 대형 암석 25개를 경질 토양에서 시험한 성공률. 학습 형상의 88%와 거의 같다.

결과는 토사를 많이 담는 궤적이 개별 암석 조작으로 자연스럽게 전이되지 않음을 보여준다. 암석의 위치와 자세에 맞춰 정렬하고, 버킷 진입 깊이를 조절하며, 포획 여부에 따라 컬링하는 목적 특화 정책이 필요했다.

가장 큰 차이는 소형 암석·경질 토양에서 나타났다. 작은 암석은 버킷 뒤로 완전히 가려지기 쉽다. 인간은 암석의 마지막 위치를 기억하고 지면 변화를 읽으며 조작을 이어가지만, 현재 시스템은 시각 추적이 끊긴 뒤 상태를 안정적으로 복원하기 어렵다.

숫자를 읽을 때의 주의점

실제 시험은 총 40회이며 네 조건에 각 10회가 배정됐다. 70%는 중요한 현장 증거지만, 다양한 지질과 경사, 날씨, 복수 암석 환경까지 일반화된 상용 성능으로 해석하기에는 표본이 작다.

06 · Emergent behavior

단단한 토양을 만나자, 버킷은 우회하는 법을 배웠다

경질 토양에서 버킷의 수평 이동 거리는 연질 토양보다 약 40% 길었다. 정책은 단단한 지면을 곧바로 파고들기보다 표면을 따라 암석을 끌어 정렬한 뒤 퍼담았다. 반대로 연질 토양에서는 짧은 경로로 직접 관입했다.

연구진은 이를 명시적인 토양 분류기의 결과가 아니라, 초기 관입 시 토크가 커질 때 저항을 피해 표면 드래깅으로 전환한 창발적 행동으로 해석한다. 정책은 “경질 토양”이라는 라벨을 입력받지 않았지만 작업 성공에 유리한 대응 방식을 학습했다.

정책은 토양의 이름을 맞히지 않았다. 대신 저항을 느끼고, 성공에 유리한 움직임으로 바꿨다.

07 · Failure modes

성능을 막은 것은 더 큰 네트워크가 아니었다

시뮬레이션과 실제 사이에는 24%포인트의 성공률 격차가 있다. 논문이 보고한 실패 사례를 보면, 주된 원인은 정책의 표현력 부족보다는 가림으로 인한 상태 손실과 단순화된 토양 모델에 있다.

  1. 지각과 가림 고정된 캐빈 센서는 근접 조작 시 암과 버킷에 가려진다. 작은 암석의 완전 추적 손실이 주요 실패 원인이다.
  2. 부분 매립 암석 LiDAR는 노출된 표면만 관측하므로 실제 크기와 매립 깊이를 충분히 표현하지 못한다.
  3. 미모델링 토양 동역학 암석–토양 결합, 지면 높이 변화, 버킷 내부 토사 축적과 넘침은 준정적 2D 모델에 충분히 반영되지 않는다.
  4. 회전 제어 오차 거친 회전 동역학 모델로 정렬이 어긋나 큰 암석이 버킷 측면에 끼는 사례가 발생했다.
  5. 제한된 실험 범위 실제 시험은 40회, 두 가지 암석 크기와 두 가지 토양 조건에 한정됐다. 다양한 경사와 지질에서의 재현성은 아직 검증되지 않았다.
  6. 사람의 초기 개입 목표 암석 분할은 사용자가 약 5개 픽셀을 지정해야 시작되므로 완전 무인 작업은 아니다.

고충실도 입자 기반 토양 시뮬레이션은 일부 현실 격차를 줄일 수 있지만, 연구진은 대규모 병렬 강화학습에 필요한 계산비용이 현재 지나치게 크다고 본다. 후속 과제로는 가림을 견디는 시간 모델과 현장 정리에 필요한 다중 암석 시나리오가 제시됐다.

08 · Interpretation

다음 돌파구는 더 큰 정책보다 더 오래 기억하는 지각이다

논문에서 직접 뒷받침되는 해석

이 연구의 성과는 70%라는 숫자만이 아니다. 단순화된 토양 모델과 암석당 20개 점이라는 작은 입력으로도 작업에 필요한 반응 행동을 학습할 수 있음을 실제 산업 규모 장비에서 보였다. 시뮬레이션과 실제 사이의 24%포인트 격차는 주로 가림과 미모델링 환경 상호작용에서 나타났다.

연구와 제품 개발에 주는 세 가지 함의

  1. 희소 관측도 작업 중심으로 구성하면 충분할 수 있다. 범용적으로 완전한 3D 장면을 복원하는 대신, 목표 암석과 장비 상태처럼 행동 결정에 필요한 정보에 집중함으로써 계산량과 시스템 복잡도를 낮출 수 있다.
  2. 시뮬레이터는 완벽한 복제본이 아니라 유용한 행동을 만드는 훈련장일 수 있다. 준정적 2D 토양 모델은 현실을 모두 재현하지 못했지만, 토양 저항에 반응하는 전략을 학습시키는 데는 유효했다.
  3. 현장 성능을 높이려면 가림 중 상태 추정과 복구가 필요하다. 마지막 관측을 기억하고, 불확실성을 추적하며, 필요할 때 시야를 확보하는 재탐색 동작이 작은 암석의 실패를 직접 겨냥한다.
분석자의 제안 · 논문에서 검증된 결론은 아님

후속 시스템은 암석 상태 추정기에 가림 중 예측, 불확실도, 재탐색 행동을 포함하고 버킷 내부 토사 축적과 변화한 지면까지 상태로 반영할 필요가 있다. 성공률뿐 아니라 작업시간, 에너지, 버킷·암석 충격과 재시도 횟수를 함께 최적화해야 인간 운전자와 공정 수준에서 비교할 수 있다.

Reader takeaway

이 논문을 한 문장으로 다시 읽는다면

자율 굴착의 가능성을 결정하는 것은 언제나 더 많은 센서나 더 복잡한 물리가 아니라, 제한된 관측으로도 현장 저항에 반응하고 실패에서 복구할 수 있는 폐루프 시스템이다.

  • 표준 버킷만으로 실제 암석 제거가 가능하다는 현장 증거를 제시했다.

  • 상용화까지의 핵심 과제는 가림 대응, 지형 변화 모델링, 더 넓은 현장 검증이다.
