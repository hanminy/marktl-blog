    RL for Robot Foundation Models

    엔드투엔드 강화학습의 정면돌파보다 현실적인 전략: 제너럴리스트가 스페셜리스트의 탐색을 돕고, 스페셜리스트의 경험이 다시 제너럴리스트를 강화하는 순환.

    Sergey Levine UC Berkeley · Physical Intelligence 32분 14초 2026-06-08 로봇 · 강화학습 · VLA
    핵심 논지부터 읽기 원본 영상 열기 ↗
    Executive thesis

    하나의 거대한 RL 문제로 풀지 말고, 순환 구조로 분해하라

    01 / THESIS
    로봇 파운데이션 모델을 RL로 엔드투엔드 학습하는 일은 아직 어렵다. 대신 작은 스페셜리스트 + 샘플효율 RL과 대형 제너럴리스트 VLA를 양방향으로 연결하라.
    01 · PRETRAIN 제너럴리스트 구축

    대규모 데모·웹·로봇 데이터로 지식과 일반화를 학습한다.

    02 · BOOTSTRAP 스페셜리스트 지원

    VLA의 표현과 행동을 prior로 주어 어려운 과제의 탐색을 좁힌다.

    03 · MASTER 실세계 RL 숙달

    작은 정책이 병목 단계를 빠르고 정밀하게 마스터한다.

    04 · DISTILL 경험을 다시 통합

    스페셜리스트의 자율 데이터를 제너럴리스트로 증류하고 반복한다.

    Motivation

    우리는 실행 계획이 아니라 실제 실행을 원한다

    “집을 청소하고, 빨래를 개고, 저녁을 차려줘”라는 요청에 텍스트만 돌려주는 모델과 물리 세계에서 행동하는 모델 사이에는 큰 간극이 있다.

    02 / MOTIVATION

    물리 세계의 파운데이션 모델이 해결해야 할 것

    • 새로운 환경과 물체에서도 무너지지 않는 일반화
    • 한 번의 동작이 아닌 다단계·장기 호흡 지시 수행
    • 실수 이후 멈추지 않고 복구해 계속 진행하는 능력
    • “그럭저럭”이 아니라 인간 수준의 성공률과 처리 속도
    핵심 전환 — 언어 모델이 “무엇을 해야 하는지” 아는 것에서, 로봇이 “실제로 해내는 것”으로.
    Training anatomy

    Pre-training은 지식, post-training은 그 지식을 쓰는 능력

    03 / RECIPE
    01

    Pre-training

    방대한 웹·로봇 데이터에서 사실, 시각 패턴, 언어 지시, 다양한 행동의 공통 구조를 배운다.

    • 폭넓은 지식
    • 새 상황으로의 일반화
    • 언어와 시각의 연결
    →
    02

    Post-training

    고품질 데이터와 RL을 이용해 이미 아는 것을 구체적인 과제의 성공, 속도, 강건성으로 바꾼다.

    • 과제 숙달
    • 낮은 실패율
    • 짧은 사이클 타임
    Complementary strengths

    지도학습은 “많이 안다.” RL은 “완벽하고 빠르게 해낸다.”

    04 / COMPLEMENTS

    지도학습이 주는 것

    • 다양한 물체와 환경에 대한 지식
    • 처음 보는 상황에서도 시도하는 능력
    • 언어 지시를 행동으로 연결하는 기반

    RL이 채우는 것

    • 특정 과제의 높은 성공률
    • 군더더기 없는 빠른 궤적
    • 실패 상태에서의 복구 경험
    대체재가 아니다. Pre-training이 “요리학교의 폭넓은 기본기”라면 RL은 “김밥 하나를 만 번 말아 얻은 숙련”이다. 좋은 로봇은 둘을 모두 가져야 한다.
    The hard intersection

    Big model × sample-efficient RL × hard task

    각 조건은 두 개씩 조합하면 기존 기법으로 다룰 수 있지만, 세 조건이 동시에 걸리면 탐색·안정성·계산비용이 정면충돌한다.

    05 / TRILEMMA
    Big model 수십억 파라미터 VLA를 noisy policy gradient로 직접 업데이트
    Sample-efficient 수십억 스텝이 아니라 몇 시간의 실제 경험으로 학습
    Hard task 기존 데이터에 없는 새로운 전략을 탐색해 발견
    구조적 충돌 — 샘플효율을 높이려면 기존 정책 근처에 머물러야 하지만, 어려운 과제는 기존 정책 밖의 새로운 전략을 요구한다. 큰 모델은 작은 수의 잘못된 업데이트에도 무너지기 쉽다.
    두 조건의 조합 대표 사례 빠져 있는 조건
    Big model + sample-efficient RL LLM post-training처럼 이미 아는 행동을 배치 근본적으로 새로운 물리 전략
    Big model + hard task 대규모 병렬 시뮬레이션 RL 실세계 샘플효율과 분포 일치
    Sample-efficient RL + hard task RLPD·SERL 스페셜리스트 대형 모델의 일반화
    Specialist engine

    큰 모델을 빼면, 실세계 RL은 이미 놀랄 만큼 잘 작동한다

    RLPD 기반의 작은 정책은 데모와 온라인 경험을 함께 재사용하며 실제 로봇의 정밀 조작을 몇 시간 안에 숙달한다.

    06 / SPECIALIST
    1–2시간

    과제별 학습

    실제 이미지와 로봇 상호작용으로 특정 작업장 환경의 정책을 빠르게 완성한다.

    100%

    특정 환경 성공률

    대시보드 조립, 타이밍벨트, IKEA 조립 등 정밀 과제에서 높은 안정성을 보인다.

    ½ 이하

    BC 대비 사이클 타임

    보상을 빨리 얻도록 최적화되어 사람의 머뭇거림과 불필요한 재조준을 제거한다.

    그러나 전문가는 전문가일 뿐이다. Pre-training이 없으므로 커넥터 종류, 카메라 위치, 조명, 배치가 바뀌면 일반화하지 못한다. 과제 하나마다 정책 하나가 필요하다.
    Mechanism

    새로운 알고리즘보다 중요한 것은 다섯 설계 선택의 결합

    07 / RLPD

    ① 50:50 대칭 샘플링

    매 배치의 절반은 고정 데모, 절반은 온라인 경험에서 뽑는다. 온라인 데이터가 쌓여도 데모가 희석되지 않는다.

    ② Critic LayerNorm

    본 적 없는 행동에서 특징과 Q값이 무한히 부풀어 오르는 병적 낙관을 구조적으로 억제한다.

    ③ Critic 앙상블

    여러 critic 중 무작위 두 개를 골라 더 작은 값을 사용해 과대평가를 거른다.

    ④ 높은 UTD

    로봇 스텝 하나마다 10~20번 업데이트한다. 비싼 로봇 시간 대신 상대적으로 싼 GPU 시간을 쓴다.

    ⑤ 엔트로피 탐색

    SAC의 확률적 정책을 유지해 초기에 한 행동으로 너무 빨리 굳는 것을 막는다.

    + 인간 개입

    막히는 순간 사람이 올바른 방향으로 교정하고, 그 경험을 replay buffer에 그대로 넣는다. Off-policy이기 때문에 가능하다.

    offline demos ─┐
               ├─► batch: 50% demos + 50% online ─► critics + actor update × 20
online rollout ┘                                  │
      ▲                                           │
      └──────── improved policy ◄─────────────────┘
    파인만식 설명 — 신입이 직접 한 번 연습할 때마다 영상을 20번 복기한다. 코치 10명 중 매번 두 명에게 물어 더 짠 점수를 따르고, 선배의 시범 영상도 학습 끝까지 절반씩 계속 본다.
    Distillation

    전문가의 손기술을 제너럴리스트의 일반화 능력에 이식한다

    08 / RLDG

    RLDG의 3단계

    1. RL Policy Training
      Ethernet·VGA·USB 등 과제별 전문가 또는 어려운 삽입 단계만 학습한다.
    2. Experience Collection
      완성된 정책을 밤새 자율 실행해 일관되고 빠른 성공 궤적을 모은다.
    3. Generalist Finetuning
      OpenVLA는 LoRA로, Octo는 전체 파인튜닝으로 경험을 흡수한다.
    결과 — 개별 전문가는 자기 커넥터만 다루지만, 증류된 제너럴리스트는 학습 때 보지 못한 커넥터에도 정밀 삽입 기술을 전이한다.

    더 일관된 정답

    RL 정책은 같은 상태에서 일관된 행동을 내므로 사람 데모의 mode averaging 문제를 줄인다.

    망설임이 없는 궤적

    사람의 멈칫함과 재조준 대신, 보상에 맞게 최적화된 빠르고 군더더기 없는 행동이 담긴다.

    정책 자신의 상태 분포

    실제 실행 중 발생한 어긋남, 미끄러짐, 복구가 데이터에 포함되어 배포 상황과 더 잘 맞는다.

    같은 개수의 성공 사례라면, RL 롤아웃이 사람 데모보다 파운데이션 모델의 학습 데이터로 더 효과적이었다.

    The missing direction

    좋아진 제너럴리스트가 다음 전문가의 학습을 돕지 못한다면, 고리는 아직 닫히지 않았다

    09 / REVERSE

    필요한 역방향

    기존 흐름

    스페셜리스트의 RL 데이터 → 제너럴리스트 개선

    ↔

    추가할 흐름

    제너럴리스트의 지식과 행동 prior → 스페셜리스트 탐색 지원

    핵심 질문 — 이미 “그럭저럭” 할 줄 아는 VLA를 옆에 두고, 왜 작은 RL 정책이 처음부터 무작위로 헤매게 두는가?
    RL Token

    큰 모델은 얼리고, 작은 RL에게 무엇을 보고 어떻게 하려는지 알려준다

    10 / RLT
    1. π*0.6 VLA의 내부 표현 N×2048을 cross-attention으로 압축해 RL token 1×2048을 만든다.
    2. 작은 actor·critic에 RL token과 VLA가 제안한 action chunk를 함께 입력한다.
    3. BC 정규화로 RL 출력이 VLA에서 너무 멀어지지 않게 한다.
    4. Critic이 확실한 개선을 찾았을 때만 prior를 벗어나도록 학습한다.
    탐색의 재정의 — 무작위 행동에서 시작하는 0→100 문제가 아니라, 제너럴리스트의 그럭저럭 되는 행동에서 시작하는 70→100 문제로 바꾼다.
    중요한 구분 — RLT 결과는 독립적인 작은 정책이 아니다. 추론할 때도 VLA가 RL token과 action chunk를 공급해야 하므로, VLA 위에 붙인 특화 어댑터에 가깝다.
    Bottleneck-only RL

    긴 과제 전체가 아니라 가장 정밀한 병목 단계만 RL로 다듬는다

    Which data do we use?

    최종 성공만 쓰면 대부분을 버리고, 전부 쓰면 실패까지 모방한다

    12 / DATA

    A · 최종 정책만

    장점: 전부 좋은 데이터라 단순 BC로 충분하다.

    대가: 초기 실패, 중간의 실수와 복구 등 RL이 수집한 대부분의 경험을 폐기한다.

    B · 전체 로그

    장점: 데이터가 많고 실수·복구·변동성을 포함한다.

    대가: 단순 BC는 나쁜 행동도 정답처럼 복제하므로 평균 품질에 묶인다.

    원하는 해법 — 실패를 버리지 않고 “이쪽은 아니다”라는 방향 정보로 사용하면서, 생성되는 행동은 좋은 데이터 쪽으로 밀어야 한다.

    초기 로그

    대부분 실패. 보상 근처에도 가지 못하지만 어떤 영역이 나쁜지 알려준다.

    중간 로그

    성공과 실패가 섞이고, 어긋남 뒤 재시도하는 복구 궤적이 가장 풍부하다.

    최종 로그

    빠르고 깨끗하지만 양이 적고, 정책이 실패 상태에서 어떻게 회복하는지 충분히 담지 못한다.

    Mathematical climax

    RL의 정책 개선은 조건부 생성과 같은 모양이다

    CFGRL은 디퓨전의 classifier-free guidance를 “좋은 행동 쪽으로 분포를 기울이는 제어 가능한 정책 개선 연산자”로 재해석한다.

    13 / CFGRL
    J(πθ) = Eτ∼πθ[Σt γtr(st,at)] − β Es[DKL(πθ(a|s) ‖ π̂(a|s))]

    보상을 최대화하되, 모든 데이터에 맞춘 참조 정책 π̂에서 너무 멀어지지 말라는 목적함수다.

    π(a|s) ∝ π̂(a|s) · exp(A(s,a))1/β

    정답 정책은 전체 데이터 분포에 행동의 좋음을 지수적으로 곱해 좋은 쪽으로 기울인 형태다.

    p(o|s,a) = f(A(s,a)) / Z(s)
    π(a|s) ∝ π̂(a|s) · p(o|s,a)w

    좋음을 이진 최적성 변수 o로 표현하면 CFG와 동일해진다. 대응 관계는 w = 1/β.

    가장 중요한 통찰 — CFG는 학습 알고리즘이 아니라 추론 시점 방법이다. 모델은 한 번 학습하고, 배포할 때 guidance weight로 보수적·공격적 개선 정도를 바꿀 수 있다.
    Visual intuition

    나쁜 데이터를 지우지 않고, 좋은 모드의 밀도만 증폭한다

    14 / GUIDANCE

    w = 0 · Unconditional

    “데이터에 있던 그대로.” 좋은 행동과 나쁜 행동을 모두 재현한다.

    w = 1 · Conditioned

    “잘된 쪽으로.” 방향은 맞지만 좋은 영역과 나쁜 영역의 밀도 차이가 아직 작다.

    w > 1 · Guided

    “잘된 쪽으로 훨씬 세게.” 작은 선호도 차이를 지수적으로 증폭해 좋은 데이터의 모드에 집중한다.

    왜 AWR보다 안정적인가

    AWR은 나쁜 샘플의 가중치를 거의 0으로 만들어 실효 배치 크기를 축소한다. CFGRL은 좋은 샘플을 o=1, 나쁜 샘플을 o=0의 예시로 사용해 모든 샘플을 학습 신호로 유지한다.

    Guidance를 과도하게 키우면

    다양성이 무너지고 원래 데이터 분포 밖으로 밀려날 수 있다. 이미지 생성에서 과도한 CFG scale이 결과를 태우듯, 로봇에서도 적절한 w를 선택해야 한다.

    20 / SUMMARY
    1. Pre-training과 RL post-training은 상보적이다. 전자는 지식·일반화, 후자는 특정 과제의 숙달·속도를 제공한다.
    2. 실세계 성공이 목표라면 post-training도 실세계에서 해야 한다. 시뮬레이터에서 배운 정책은 결국 시뮬레이터의 가정에 묶인다.
    3. 핵심 난제는 big model × sample-efficient RL × hard task다. 세 조건을 동시에 만족시키는 대신 문제를 분해하는 것이 현재의 실용적 전략이다.
    4. 작은 스페셜리스트 RL은 이미 강력하다. RLPD·SERL은 특정 환경에서 1~2시간 학습, 높은 성공률, BC보다 짧은 사이클 타임을 달성한다.
    5. RL 롤아웃은 사람 데모보다 더 좋은 교재가 될 수 있다. 일관되고 빠르며, 정책 자신의 상태 분포와 복구 경험을 담는다.
    6. 제너럴리스트는 탐색을 위한 행동 prior다. RLT는 내부 표현과 action chunk를 이용해 무작위 탐색을 의미 있는 행동 근처의 탐색으로 바꾼다.
    7. CFGRL은 실패 데이터를 버리지 않는다. 좋고 나쁜 모든 데이터를 조건부 학습에 사용하고, 추론 시 guidance로 좋은 모드에 집중한다.
    8. 최종 형태는 단방향 파이프라인이 아니라 순환이다. 제너럴리스트가 전문가를 부트스트랩하고, 전문가의 자율 데이터가 다시 제너럴리스트를 강화한다.

    문제

    희소 보상 아래의 표준 RL은 USB를 삽입할 때 의미 있는 방향으로 접근하기보다 궤적 전체에서 무작위 노이즈를 낸다. 성공을 한 번도 보지 못하면 critic도 방향을 배울 수 없다.

    Levine의 답

    로봇 파운데이션 모델을 행동 사전확률로 사용하라. RLT의 BC 항처럼 참조 행동 근처에서 탐색하면 이미 알고 있는 구조를 이용해 성공 가능성이 높은 상태에 먼저 도달한다.

    액션 값을 무작위로 흔드는 대신, 언어 입력을 바꾸며 의미 공간에서 탐색할 수 있다.

    행동 prior

    아기가 구멍을 보고 손을 뻗듯, VLA가 이미 아는 시각·언어 구조를 탐색의 출발점으로 사용한다.

    한계

    참조 정책 근처에 묶이면 진정으로 새로운 전략을 발견하기 어려울 수 있다.

    전제

    파운데이션 모델이 이미 상당히 많이 알고 있다는 믿음이 있을 때 매우 효율적인 탐색 방법이다.

    23 / DEEP DIVE
    왜 RL 데이터가 같은 개수의 성공한 사람 데모보다 좋은가?

    1. 사람의 행동은 같은 상태에서도 흔들린다

    사람은 기억, 의도, 망설임에 따라 같은 장면에서 서로 다른 행동을 고를 수 있다. BC는 이 다봉 분포를 평균내어 어느 쪽도 아닌 애매한 행동을 출력할 수 있다. RL 정책은 현재 상태의 함수로 최적화되어 상대적으로 일관된 타깃을 제공한다.

    2. 머뭇거림이 제거되어 있다

    사람 데모에는 멈춤, 재조준, 손목 각도 수정 같은 군더더기가 포함된다. RL 정책은 할인된 보상을 최대화하기 때문에 더 짧은 궤적을 만들고, 그 빠름이 증류 데이터에 직접 담긴다.

    3. 배포 정책의 상태 분포를 반영한다

    자율 롤아웃은 정책이 실제로 만드는 작은 오차, 미끄러짐, 복구 상태를 포함한다. 그래서 깨끗한 데모만으로 배운 정책보다 복합 오차에 강해질 가능성이 높다.

    CFGRL의 학습과 추론은 실제로 어떻게 다른가?

    학습

    1. 좋은 행동과 나쁜 행동을 포함한 전체 데이터를 모은다.
    2. 가치함수로 advantage를 계산하고 o = 𝟙[A > ε] 라벨을 붙인다.
    3. 디퓨전 정책을 o 조건으로 지도학습하되, 일부 학습 예시에서 o를 무작위로 제거한다.

    추론

    1. 같은 모델에 o=1 조건과 무조건 예측을 함께 요청한다.
    2. 두 예측의 차이를 좋은 행동 방향으로 보고 guidance weight w만큼 증폭한다.
    3. w를 배포 시점에 바꿔 개선 강도를 조절한다.

    별도 actor를 policy gradient로 학습하거나 디퓨전 샘플링 체인 전체를 역전파하지 않아도 된다는 점이 대형 VLA에 중요하다.

    π0.7에서 품질 메타데이터가 왜 전제조건인가?

    자율 데이터는 확장성이 높지만 대부분의 학습 과정에는 실패와 불완전한 행동이 섞여 있다. 품질 조건이 없으면 단순 BC가 실패까지 평균적으로 복제한다.

    좋고 나쁨을 분간하는 조건화
    ↓
    지저분한 자율 데이터를 폐기하지 않고 흡수
    ↓
    실행 시 최고 품질·최단 길이 요청

    따라서 “스페셜리스트 데이터”와 “분간 능력”은 병렬 재료가 아니다. 분간 능력이 자율 데이터를 대규모로 사용할 수 있게 만드는 전제조건이다.

    RLT에서 각 구성요소는 어떤 역할을 하는가?
    구성 역할 직관
    RL token VLA 내부 표현을 1×2048로 압축 베테랑이 현재 상황을 어떻게 이해하는지 전달
    Pass-through action VLA의 action chunk를 RL에 입력 베테랑이 지금 하려던 행동을 힌트로 전달
    BC regularizer RL 출력이 prior에서 너무 멀어지는 것을 억제 더 나은 방법을 못 찾았다면 기본 행동을 따르기
    Action chunking 연속된 정밀 동작의 시간 구조 표현 한 프레임의 떨림보다 하나의 완결된 손기술을 학습
    SERL과 HIL-SERL의 차이

    SERL은 sample-efficient robotic reinforcement learning을 실제 로봇에서 돌리기 위한 소프트웨어·운영 묶음이다. RLPD, 보상 분류기, 안전한 제어, 자율 리셋, 비동기 학습을 통합한다.

    HIL-SERL은 여기에 인간 교정 개입을 더한다. 로봇이 헤매는 순간 SpaceMouse 등으로 몇 초간 올바른 행동을 보여주고, 그 데이터를 replay buffer에 넣는다. Off-policy 학습이기 때문에 현재 정책이 만들지 않은 교정 경험도 즉시 활용할 수 있다.

    이 계보에서 RLT는 “탐색을 돕는 사람”의 자리에 파운데이션 모델을 앉힌 접근으로 이해할 수 있다.
